## 2. 변경 내용

### 2-1. `src/hooks/useChatStream.ts` (2단계 + 흡수)

- `ChatStreamMessages` 인터페이스 삭제 → 모듈 레벨 `STATUS: Record<Language, {...}>` 맵으로 대체 (8키 × 4언어).
- `UseChatStreamOptions`에서 `statusMessages` prop 제거 (타입 + 구조분해).
- `handleSendMessage` 상단에 `const status = STATUS[language] || STATUS.ko;` 추가.
  - 일반 함수(매 렌더 재생성)라 `language`를 신선하게 캡처 → stale closure 없음.
- 소비 8곳을 `status.X`로 재배선:
  - 기존 `statusMessages.X` 6곳: `uploadFailed`, `identifyingPill`, `analyzingImage`, `analyzingPaper`, `watchingVideo`, `fetchingUrl`.
  - **하드코딩 한국어 2곳 흡수**: `'Gemini가 대용량 문서를…'` → `analyzingLargeDoc`, `'첨부파일 분석 중...'` → `analyzingAttachment`. en/es/fr 번역 신규 추가(기존 i18n 누락 = 비한국어 사용자에게 한국어 노출되던 버그 동시 해소).

### 2-2. `App.tsx` (1단계 + 2단계 정리)

- 2단계: `useChatStream(...)`에 넘기던 `statusMessages: {...}` subset 객체(10줄) 제거.
- 2단계 부수효과: subset에서만 쓰이던 status 6키(`uploadFailed`·`analyzingImage`·`analyzingPaper`·`watchingVideo`·`fetchingUrl`·`identifyingPill`)를 i18n에서 삭제(이관됐으므로 dead).
- 1단계: 죽은 키 8개 삭제 — `profileUpdated`·`renameFailed`·`analyzingDoc`·`analyzingFile`·`analyzingVideo`·`preparingSession`·`checkingYoutube`·`analyzingTranscript`. 레포 전체 grep으로 참조 0 확인 후 삭제. `profileUpdated` 참조 죽은 주석(`// showToast(t.profileUpdated, ...)`)도 제거.
- **순효과**: i18n 블록이 15키×4언어 → `profileUpdateFailed` 1키×4언어로 축소. 유일한 생존 소비처는 `t.profileUpdateFailed` 1곳(프로필 변경 실패 토스트).
