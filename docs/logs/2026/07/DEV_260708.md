## §1. 배경

기존 별자리 렌더러는 실시간 서울 하늘(alt/az) 전용 + 쿨 블루 "천체 관측 앱" 미학. 사용자 요청으로 **웜 골드 포스터 심미성**으로 리스킨하되 실좌표·인터랙션은 유지. 방향은 프로토타입에서 확정(하이브리드 리스킨·정적 기본+관측지 토글·실루엣 생략·영어 별이름+크롬 i18n).

## §2. 순수 헬퍼 (`utils/celestialMath.ts`)
- **`projectStaticChart(stars, W, H, padXFrac=0.15, padYFrac=0.19)`**: RA/Dec centroid 기준 정적 투영(RA 왼쪽·북쪽 위) + 바운딩박스 자동맞춤(프레임 ~70% 채움). 시간·장소 무관. **좌표 미변형**.
- **`applyViewTransform(pts, cx, cy, {scale,rot,px,py})`**: 화면공간 줌·회전·팬. 파이프라인 **마지막 단계**라 두 모드 공통.
- 검증: `scripts/test-constellation-projection.mjs`(gitignore) — in-bounds·RA/Dec 방향·회전+줌+팬 합성 PASS.

## §3. 정적 기본 + 관측지 분기 (§투영)
- `observerMode`(기본 `false`) 상태 추가. `!observerMode`면 `projectStaticChart`(중앙 고정 구도), 아니면 기존 `equatorialToHorizontal`→`horizontalToCanvas`(실시간 하늘, horizon culling 유지).
- **이중 줌 버그 방지**: 관측지 투영은 `zoom` 제외한 base scale(`height*0.4*(data.zoom||1)`)로 계산하고, 줌은 `applyViewTransform`이 전담.
- 투영 후 `applyViewTransform`으로 줌·회전·팬을 좌표에 bake → 이후 draw·hover의 `+ panOffset` 오프셋 전부 제거(선·별·라벨·hover hit-test). auto-center·은하수는 관측지 모드에서만.

## §4. 웜 골드 리스킨
- `getStarColor` 쿨 블루 → **웜 골드 램프**(`#ffeecd`~`#ffcc88`).
- 별: **등급별 헤일로 축소**(어두울수록 tight, 밀집 asterism 뭉침 방지) + **십자 스파이크**(mag<3.0) + 웜 코어(`#fff6dc`).
- 연결선: **골드 그라디언트 글로우**(중앙 `rgba(240,205,150,.9)`), 블루 코어 제거.
- 배경: 기존 딥 스페이스 다크 유지 + **보라/블루 성운 2개**(프로토에서 밝게 시도 후 롤백된 다크 유지). 라벨 색 웜 골드.

## §5. 포스터 타이틀 + 크롬 재구성
- 전폭 헤더바 제거 → **좌상단 포스터 타이틀**(현지어 별자리명 + 골드 룰, 심볼·라틴 보조표기 없음).
- 우상단 클러스터: 모드 배지(정적/관측지) + **관측지 토글 아이콘 버튼**(`fa-location-crosshairs`) + 스냅샷. 시간 컨트롤(◀▶·재생)은 **관측지 모드에서만**.
- 우하단: 줌 ±  + **회전 버튼(클릭 +15°)** + 초기화.

## §6. i18n (KO/EN/ES/FR)
- `labels`에 `mag·observer·staticBadge·observerBadge·zoomIn·zoomOut·rotate·reset` 추가. 툴팁·배지·호버 등급 라벨 현지화. **별 이름은 영어 유지**, RA/DEC는 만국 공통.

## §7. 스냅샷

## §8. 반응형·모바일 UX 보정 (앱 렌더 확인 후)

앱 실렌더 스크린샷 피드백 반영:
- **반응형 캔버스**(`updateCanvasSize`): 하드코딩 500/800px 제거 → **컨테이너 실제 폭 측정**해 캔버스를 딱 맞춤(모바일 잘림/여백 해소). 모바일은 세로 여유 있는 비율(`width*0.8`), 웹 `*0.6`. 부수: 리사이즈 시 `ctx.scale(2,2)` 누적되던 잠재 버그를 `setTransform(1,0,0,1,0,0)` 리셋으로 수정.
- **모바일 별자리 확대**: `projectStaticChart` 여백을 모바일에서 타이트(padX 0.09·padY 0.10, 웹 0.12) → 작은 카드를 더 채움.
- **타이틀 겹침 해소**(`projectStaticChart`에 `topInset` 파라미터 추가, 기본 0): 상단 타이틀 밴드(웹 74px·모바일 54px)를 확보하고 별자리를 그 아래 영역에 중앙 정렬 → 좌상단 포스터 타이틀과 별이 안 겹침.
- **관측지 시간 컨트롤 재배치**: 상단 우측(타이틀과 겹치던)에서 **하단 중앙**으로 이동(관측지 모드만). 상단 우측엔 모드배지+토글+스냅샷만.
- **우측 컨트롤 축소**: 줌±·회전·초기화 버튼 `w-8 h-8 sm:w-10 sm:h-10` → `w-6 h-6 sm:w-7 sm:h-7`.
