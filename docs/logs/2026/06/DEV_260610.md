## 3. ★ 메가박스 direct 엔드포인트 발견 (browserless 탈출)

기존 fetchMegabox는 browserless로 `/booking/timetable`을 30~60초 렌더 + DOM 파싱(좌석수 못 얻음). 엔드포인트 탐색 결과:

- **`POST https://www.megabox.co.kr/on/oh/ohc/Brch/schedulePage.do`** — Cloudflare/browserless 불필요, JSON 직접 반환.
- 페이로드: `{masterType:"brch", detailType:"area", areaCd:"", brchNo1:<brchNo>, brchNo:<brchNo>, firstAt:"Y", playDe:"YYYYMMDD", sellChnlCd:"MEGABOX"}`
  - `areaCd`는 **빈 값 허용**(틀린 값 99는 0건). `brchNo`가 실제 키.
- 응답 `megaMap.movieFormList[]` 필드: `movieNm`/`theabExpoNm`(상영관)/`restSeatCnt`·`totSeatCnt`(**좌석수!**)/`playStartTime`·`playEndTime`/`admisClassCdNm`(등급)/`moviePosterImg`/`playKindNm`(포맷)/`playDe`. `movieFormDeList`는 7일치 날짜.

> 효과: 렌더 30~60초 → **direct ~0.1초**, 그리고 기존 DOM 스크랩으론 못 얻던 **좌석 잔여/총석 확보**. 엔드포인트 출처는 페이지 참조 `/js/megabox-brch.js`(`schedulePage.do`).

## 7. 지연 일관성 문제

3사 병렬 로드 시 롯데·메가박스(direct)는 0.1~0.3s, CGV(browserless)만 ~7s → "CGV 고장났나" 싶은 비대칭. 해법을 ① CGV 지연 자체 단축 ② 남는 콜드를 UX로 매끄럽게 2단으로 접근.

## 8. CGV direct 서명 — Cloudflare Bot Management 차단 (불가)

CGV HMAC 서명(`ts|pathname|body`, SECRET 기보유)을 Node `crypto.createHmac`로 재현해 `api.cgv.co.kr` 직접 호출 시도 → **HTTP 403**.
- 응답: *"비정상적으로 CGV에 접속한 것이 확인되어 이용이 제한되었어요"* (server: cloudflare, CLIENT_IP=한국 IP).
- JS 챌린지(1회 풀이)가 아니라 **봇 관리 차단** — 서명·한국 IP 무관하게 Node의 TLS/HTTP 지문이 걸림. browserless가 되는 건 **실 헤드리스 Chrome**이라 봇 탐지를 통과하기 때문.
- **결론: CGV는 browserless 불가피.** direct 불가.

## 9. 서버 SWR 캐시 + 스켈레톤

direct가 막혔으니 일관성은 캐시+스켈레톤으로.
- **SWR 인메모리 캐시**(`getShowtimes`): fresh 120s(그대로) / stale 30분(즉시 반환 + 백그라운드 갱신) / 그 외·miss 동기 fetch. 키 `chain:code:date`. `?nocache=1`로 강제 신선.
  - 실측: **CGV 콜드 7.3s → 웜 0.003s (2400배)**, 메가박스 0.15s → 0.002s.
- **스켈레톤**: 스피너 → 카드 모양 shimmer 골격으로 레이아웃 예약(점프 제거), 3사 동일 스켈레톤 시작 + 최소 320ms 표시로 빠른 2사 "번쩍" 방지.
- meta 표기: 캐시 배지·"N초 전"(상대) 제거 → **`오후 H:MM 조회`**(절대 시각, `toLocaleTimeString`)로 단순화.

## 10. CGV 콜드 최적화 (~7s → ~2.5s)

browserless 전략 벤치마크(`_cgv-bench*.mjs`, 측정 후 삭제):

| 전략 | 콜드 | 비고 |
|------|------|------|
| networkidle2 + 2s (원래) | ~6.9s | nav가 광고·트래커까지 대기 |
| domcontentloaded + 0s (S3) | ~2.0s | nav 0.6s |
| nav 생략 (about:blank fetch) | ❌ | Cloudflare 차단 — nav는 필수 |
| **api robots.txt goto + 리소스차단 (S6+block)** | **격리 1.3~1.6s / 실서버 2.4~3.4s** | **적용** |

- **범인 = `networkidle2` + 고정 2s 대기.** `domcontentloaded` + 이미지/폰트/CSS `setRequestInterception` 차단, `api.cgv.co.kr/robots.txt`(가벼운 텍스트)로 직접 goto해 Cloudflare 통과.
- **남은 ~2s floor = browserless 기동(실 Chrome spin-up, 1.5~2s 변동).** nav·API는 이미 한계치(0.2s+0.4s). 이 floor 제거는 **세션 재사용(puppeteer.connect 영구 세션)** 뿐인데, REST→영구세션 구조 변경 + 세션 유지 과금 + 산발 조회라 실익 작음 → **미채택**(캐시가 반복을 0초로 만듦).
- 실용 floor ≈ **2.5s**(처음 보는 CGV 지점 1회), 이후 캐시로 즉시.
