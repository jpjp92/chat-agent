## §1. 변경 개요

빈(웰컴) 화면을 정비. 현행 비주얼(violet primary·그라데이션 타이틀·`rounded-[28px]` 입력창·라이트/다크 색상)은 전부 그대로 재사용, 구조만 변경.

| 영역 | 변경 |
|---|---|
| 모델 선택기 | **반응형 하이브리드**: 데스크톱=입력창 우측(Claude식) / 모바일=헤더 좌측(Gemini식). 3.5·2.5만 |
| 헤더 | 모델 제거(데스크톱)·**bare 플로팅**(pill 배경 제거): 좌=햄버거+(모바일)모델 / 우=아바타 |
| 첨부 아이콘 | `fa-paperclip` → **`fa-plus`** |
| 웰컴 메시지 | 2단(큰 인사+부제) → **한 줄** `무엇을 도와드릴까요?`(모바일·웹 공통, 1줄에 들어가게 간결화) |
| 추천 칩 | 신규 4종(검색·영화·약·코드), 라인 아이콘, 클릭 시 입력창 채움. **모바일 숨김**(`sm+`만), 데스크톱 중앙 wrap |
| 웰컴 레이아웃 | 데스크톱=그리팅+입력창(중앙)+칩 / **모바일=그리팅 중앙+입력창 하단**(기존 위치 유지) |
| 입력창 폭 | 웰컴·대화 모두 `max-w-4xl`로 통일(전환 시 폭 점프 제거). main 콘텐츠 래퍼 3xl→4xl |

## §2. 파일별 변경

- **components/SuggestChips.tsx** (신규): 칩 4종 i18n 테이블(ko/en/es/fr) + `onSelect(sample)`. 모바일 숨김(`hidden sm:flex`), `flex-wrap justify-center`, 모바일 축소(`text-xs px-2.5 py-1.5`).
- **components/ChatInput.tsx**: 모델 선택기 통합(데스크톱 전용 `hidden md:block`, 드롭다운 `welcome`=아래/그외=위), 모델 i18n, `prefill {text,ts}` 효과(editValue 패턴 재사용), 첨부 `+`. **폼 `overflow-hidden` 제거**(드롭다운이 폼 밖으로 열려 잘리던 버그 수정 — 폼 배경은 자기 `rounded-[28px]`로, 드래그 오버레이는 자체 rounded로 클리핑).
- **components/Header.tsx**: bare 플로팅. 모델 선택기는 **모바일 전용**(`md:hidden`, 드롭다운 아래로) 복원. 데스크톱은 아바타만.
- **components/WelcomeMessage.tsx**: 한 줄 그리팅(`greetings` 맵, 4언어). `무엇을 도와드릴까요?`.
- **App.tsx**: 모델 props를 Header·ChatInput **양쪽** 전달. `isWelcome` 분기 — 데스크톱 웰컴은 main 중앙 입력창(`hidden md:block`), 모바일은 footer 입력창(`isWelcome ? md:hidden`)으로 항상 하단. `prefill` state(칩→입력창). 폭 `max-w-4xl` 통일.

## §3. 반응형 배치 요약

| | 모바일 (<md) | 데스크톱 (md+) |
|---|---|---|
| 모델 선택기 | 헤더 좌측 | 입력창 우측 |
| 웰컴 입력창 | **하단(footer)** | 중앙(main) |
| 추천 칩 | 숨김 | 표시(중앙 wrap) |
| 그리팅 | 한 줄 중앙 | 한 줄 중앙 |

> 구현: main 중앙 입력창 `hidden md:block`, footer 입력창 `isWelcome ? 'md:hidden' : ''`. 모바일은 웰컴·대화 모두 입력창이 footer 하단(기존 위치와 동일). 데스크톱만 웰컴에서 중앙→대화 시 하단.

## §4. 검증

- tsc 0 (반복 통과). `npm run build`는 로컬 WSL에서 OOM Killed(메모리 한계, 코드 무관) → 실제 빌드는 Vercel/CI 확인 권장.
- dev 스크린샷 점검: 데스크톱 다크/라이트, 모바일 헤더 모델·하단 입력창·칩 숨김 정상. 모델 드롭다운(overflow 수정 후) 정상 표시.
- 잔여 폴리시(선택): 웰컴↔대화 전환 시 데스크톱 ChatInput 리마운트(첫 전송 시 입력 비워지므로 무해, 포커스만 재클릭). 2 인스턴스 마운트(웰컴 데스크톱 main + 모바일 footer)는 CSS 표시 1개 — 경미한 오버헤드.
