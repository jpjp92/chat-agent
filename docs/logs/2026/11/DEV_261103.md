## 4단계-B 자유물체도 SVG

- 형식 `parameters: { object: { shape, label? }, forces: [{ kind, angleDeg, magnitudeN?, label? }] }`. `kind`(gravity·normal·friction·tension·buoyancy·drag·applied·spring·other)로 기호(mg·N·f·T·F_b·D·F·F_s)를 코드가 정한다 — canvas 는 LLM 라벨 문자열을 키워드로 찾다가 "중력 (19.6 N)" 의 `N)` 을 수직항력으로 오인했다. `label` 은 `other` 만, 6자.
- 크기는 전부 있을 때만 알짜힘(일부만 있으면 나머지를 추정할 수 없다). 합의 0.5% 미만은 평형 — LLM 의 49.05/49 반올림 흡수. 크기 없으면 같은 길이 + 각주.
- 같은 방향(±8°) 화살표는 14px 비켜 그림. 8개 초과·모르는 kind·옛 최상위 `forces` 는 canvas.
