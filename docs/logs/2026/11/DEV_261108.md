- GPT 검토(원문 페이로드) 반영 — 원문 최소화:
  - **LangChain 메시지 정규화**: 직렬화 메시지(`lc_serializable`·`lc:1 constructor`) → `{type, content}` + 있으면 `tool_calls`(인자도 마스킹)·`tool_call_id`·`name`. `content` 가 `lc_kwargs.content` 에 한 번 더 있어 원문이 2배였고, 메시지 UUID·`lc_namespace` 는 쓸모없다. 전송 직전 사본만 — 그래프 상태·SDK 요청·SSE 무관. LangSmith run/trace ID 는 그대로.
