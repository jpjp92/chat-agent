## 1. P1-2A 구현

- 분류 `lib/source-kind.ts` — 입력은 grounding title(호스트명). 호스트명 형식만 분류, 점 경계 접미사(`go.kr`·`gov` 등) + 소수 목록(bok.or.kr·kosis.kr·krx.co.kr…)은 공식, 언론·위키·집계 목록은 2차, 나머지 기타. 하니스 `tests/test-source-kind.mts` 42 — `evilgo.kr`·`kma.go.kr.evil.com`·`fakekosis.kr`·호스트명 아닌 제목은 기타.
- 표시 `SourceBar` — **차트 답변에만**(본문에 `json:chart` 가 있을 때). 칩 1~2개는 칩 옆, 3개 이상은 펼친 목록 각 줄 + 접힌 바 "출처 N개 · 공식 M". 체크 아이콘·강조색 없음(분류는 수치 검증이 아니다, §5-1).
- 로그 `[turn] sourceKinds: {official, secondary, other}` — 호출부(route.ts)가 세고 turn-log 는 키 3개 정수만 받는다(하니스 추가).
- 프롬프트 `[STATISTICS SOURCING]`(차트 지시의 `[NEVER INVENT DATA POINTS]` 뒤) — 사용자 숫자·함수 차트는 대상 아님을 명시. 1차안 뒤 실화면에서 기준·고지가 약해 보강: **제목 = 지표 + 기준 + 실제 기간**, 차트 직전 두 확인(공식 출처 없음 · 마지막 시점이 오래됨)을 해당할 때 한 문장씩. 골든 11 갱신.

## 3. 로컬은 유료 키를 안 쓰고 있었다

- 오전 화면 확인(환율·출생아·코스피)은 `[turn]` 이 `gemini-2.5-flash · modelDowngraded: true`. 로컬 `.env.local` 에 `GEMINI_PAID_FIRST` 가 없어 회원 요청도 무료 키 로테이션 → 무료 키는 3.x 검색 불가라 2.5 로 강등(설계대로). `API_KEY_TIER1` 이 있어도 스위치가 꺼져 있으면 쓰지 않는다.
- `.env.local` 에 `GEMINI_PAID_FIRST=true` 추가 후 `gemini-3.8-flash · false` 확인. **오전 화면 관찰(기준 누락 등)은 2.5 의 행동**이었다.

## 4. 차트 축 판정 버그 — 연.월 범주를 소수로

- 3.8 환율 화면에서 선이 평평하다 오른쪽 끝에서 뒤엉킴. 범주 `"2025.11"…"2026.10"` / `"25.11"…"26.10"` 을 숫자로 읽어 `2026.10 = 2026.1` → 불균등 숫자 → numeric 축. P0(11-05) 부터 있던 결함.
- 수정 `chart-axis.ts`: `연도(19xx·20xx).월(1~12)` 문자열은 숫자 아님. 두 자리 연도 `YY.MM` 은 한 라벨로는 소수(`10.05`)와 못 가르므로 **범주 전부**가 그 꼴일 때만. 하니스 30.
- 출생아 x 축 소수 눈금(1979.17…)은 함수·실제 Apex·실제 `ChartRenderer` 번들 세 경로 모두 재현 안 됨 — 재시작 후 미관찰.
