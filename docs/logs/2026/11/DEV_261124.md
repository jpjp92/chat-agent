## 3. 의학 격차 원인 (`probe-medical-35fl.mts`, 30회)

## 6. 도구 의도 11개 (`probe-tool-intents.mts`, 운영 `runLangChainPath` + 실제 도구)

도구 의도 11개(약국·병원·동물병원·영화·법령 검색·날씨·알약 식별·약 정보·법령 해석·논문·arXiv)는 선택 모델과 무관하게 **답변 생성 전체가 2.5 Flash** 다. 모델은 `SERVER_MODELS.FLASH` 를 런타임에 바꿔 비교(운영 코드에 시험용 분기 없음).

- **400 방지(구현 전 발견)**: `isThreeXFlash` 는 이름 정확 일치라 `gemini-3.5-flash-lite` 를 3.x 로 보지 않는다 → 상수만 바꾸면 이 경로가 `thinkingBudget: 0` 을 보내 400. `model-thinking.ts` 에 3.5 FL 행(budget 불가) 추가, `langchain-path.ts` 판정을 측정표(`usesThinkingLevel`)로. 기존 모델 값은 그대로.
- 1차 23문항 × 1: 오류 0 / 0 · 도구 23 / **22** · 카드 23 / 23 · 지연 7.5 / **4.6s**. fast-pass 6개는 카드 그대로라 차이 없음. arXiv 2문항은 외부 API 429 로 집계 제외.
- 합성 3개 의도 7문항 × 2회: 6.14 / **6.64**(7 : 7), 도구 14 / **12** · 지연 11.4 / **5.8s**.
- 3.5 FL 약점 두 가지가 재현됐다:
  1. **이부프로펜 질문에서 약 DB 미호출(3/3)** — drug_info 는 도구가 둘(식약처·웹)이라 단일 도구 강제가 꺼져 있었다.
