## 1. 역할별 2.5 Flash vs 3.5 Flash-Lite — 유료 키 (`probe-25-vs-35fl-roles.mts`, 48회)

- 2.5 는 운영 설정 그대로, 3.5 FL 은 `minimal`. 일반·의학·검색·함수 호출·이미지·YouTube·URL PDF·JSON 8역할 × 3회 — **실패 0**, 3.5 FL 이 모두 같거나 빠르다(일반 9.8s → 1.9s, 생각 토큰 0).
- 대신 답이 짧다(일반 ~55% · 의학 ~77% · 검색 ~33%, 출처 4 → 2) → 품질 비교로.

## 2. 답변 품질 — 블라인드 채점 (`probe-25-vs-35fl-quality.mts`)

- 운영 시스템 프롬프트 + 18문항(일반·의학·검색 각 6), gpt-6-luna 가 A/B 무작위로 채점.
- 일반 8.2 / 7.8(거의 동등, 3배 빠름) · 의학 `minimal` 8.0 / 6.8 → **`low` 7.5 / 7.2** · `medium` 7.8 / 6.7(이득 없이 느림).
- 검색은 두 모델 모두 1~4점 — 채점 모델이 2026 최신 사실을 확인 못 해 판단 불가.
- 함정: 첫 실행의 채점 요청이 400(`json_object` 는 입력에 "json" 단어가 필요)이었는데 빈 객체를 승패로 읽어 결과가 무작위였다 → 응답 상태·형식 검사를 넣고 다시 돌렸다.

## 3. 폴백 3자 — 2.5 · 3.5 FL · 3.6 `minimal` (`probe-fallback-3way.mts`, 48회)

- 세 답을 한 번에 블라인드 채점. 일반 8.4 / **8.6** / 7.8 · 의학 **7.7** / 6.8 / 6.5. 지연 3.5 FL 이 가장 빠르다.

- **게스트도 유료 키(범위 A)** — 2.5 Flash 가 맡던 호출은 회원·게스트 구분 없이 유료 키 우선, 무료 키는 유료 429 때 보조. 게스트 본 답변(3.6·3.8)은 지금처럼 무료 키.
