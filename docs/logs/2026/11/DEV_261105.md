## 2. 차트 질문 검색 (`search-gate.ts` · `router.ts`)

`data_viz` 는 렌더러 의도라 "구조화 출력 보존"으로 검색을 강제 off(08-15, 3.5 two-track 에서 차트 블록 누락) — 라우터가 검색 필요라 해도 덮어썼다. 결과: Gemini 가 출생아 2024년을 "약 21만 예측"(실제 238,317), GPT 는 "실시간 검색 불가"로 거절.
- `data_viz` 를 강제 off 에서 빼고 라우터 `needs_search` 를 따르게 함(`isGeneralIntent` 분기에 포함). 다른 렌더러는 그대로.
- 라우터 정의: true 에 "차트로 그릴 실제 통계·역사 수치(인구·가격·연도별 지수)", false 의 math 에 "함수 그래프(y = x²)". 정의 보강 전엔 Gemini 가 y = x² 에도 검색 → 차트 블록 누락.
- data_viz 지시: "검색 결과를 써도 json:chart 블록은 출력". 흩어진 수치로 차트 금지 한 줄(차트 규칙). 골든 갱신.
- 하니스: `test-search-policy` 2건(통계 → on, 함수 그래프 → off).

## 3. 인용 제거가 차트 JSON 정수 배열을 지움 (`gemini-citations.ts` · `stream-dispatch.ts`)

Gemini 출생아 답이 `"data":` 뒤 빈 채로 와 차트가 사라졌다. 가짜 인용 제거 정규식 `\s?\[\d+(?:,\s*\d+)*\](?!\()` 가 `[438, 406, …]` 를 인용 번호로 보고 지웠다 — 정수 배열 차트 전부 해당, 이전부터 있던 버그(소수 값·GPT 경로라 드러나지 않음).
- `:`·`[`·`,` 바로 뒤 대괄호는 JSON 배열로 보고 남김(lookbehind). 스트리밍은 이미 보낸 본문 끝 40자를 앞 문맥으로 — `"data":` 와 배열이 청크로 갈려도 판정. 정규식을 `stripFabricatedCitations` 한 곳으로 합침.
- 하니스: `test-gemini-citations` 2건(한 청크 · 청크 경계).
