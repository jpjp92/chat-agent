## 2. M0 — 적용 대상(§7-3)

- `animate-in` 18곳 · 10파일 전수. 메시지 밖(토스트·사이드바·입력창·컨텍스트 메뉴·로딩 화면)은 요소 단위, 메시지 안(루트·출처 줄·잘림 경고·카드 5종)은 새 메시지에서만.
- 함정: `duration-*`·`ease-out` 은 transition 전용이라 적혀 있던 500·700·1000ms 는 처음부터 무의미 · 끝난 뒤 transform 이 남으면 쌓임 맥락(컨텍스트 메뉴가 다음 메시지 밑으로 깔렸던 원인) → `backwards` · 카드는 자기가 새 메시지인지 모른다 → 루트 `data-motion="new"`.
- 확인: 토스트는 정상 동작하고 **등장 모션만** 무효였다.

## 4. 마이크 알림 문구

- 사용자 원칙(11-22): **알림 문구는 짧고 명료하게.**
- [ChatInput.tsx](../../../../components/ChatInput.tsx) 음성 인식 오류 3종을 짧게 고치고 `i18n` 표로 옮김. 전에는 ko·en 만 있어 **es·fr 사용자에게 영어**로 나왔다.

  | 상황 | 전 | 후(ko) |
  |---|---|---|
  | 권한 거부 | 마이크 접근 권한이 없거나 거부되었습니다. | 마이크 권한을 허용해 주세요 |
  | 네트워크 | 네트워크 연결 상태가 불안정합니다. | 네트워크 연결을 확인해 주세요 |
