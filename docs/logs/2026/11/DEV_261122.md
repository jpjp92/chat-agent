## 9. 인라인 LaTeX 원문 노출(사용자 피드백)

- **증상** — 카페인 구조 답변에서 `$-\text{CH}_3$`·`$=\text{O}$` 가 원문으로 보였다(한글 글꼴이라 `\` 가 `₩` 로 표시).
- **원인** — 06-24 에 통화 `$` 가 수식으로 묶이는 문제를 막으려고 단일 `$` 수식을 껐다(`singleDollarTextMath: false`, [DEV_260624 §6](../06/DEV_260624.md)). 프롬프트에 수식 표기 규칙이 없어 모델은 여전히 단일 `$` 를 쓴다.
- **수정** — 단일 `$` 수식은 꺼 둔 채, **LaTeX 명령(`\text`·`\frac` 등)이 든 `$…$` 만** `$$…$$`(인라인 수식)로 올리는 전처리 `promoteTexInlineMath`(`utils/mathNormalize.ts`)를 기존 `splitInlineDisplayMath` 앞에 끼웠다. 통화엔 역슬래시 명령이 없어 그대로다. 코드 펜스·인라인 코드 안, 공백으로 시작·끝나는 짝은 건드리지 않는다.
- **한계** — `$x^2$` 처럼 명령 없는 단일 수식은 여전히 원문이다(통화와 구별이 어려워 범위 밖).
- **화학식 정체** — 재시험에서 모델이 `$$C_8H_{10}N_4O_2$$`·`$$-CH_3$$` 로 써 렌더는 됐지만 기울임 변수체였다. 같은 줄 `$$…$$` 의 내용이 원소 기호 2개 이상 + 숫자 첨자로만 이뤄졌으면 `\mathrm{}` 으로 감싼다(`uprightChemFormulas`). `V_1`·`A_2B_3`·`x_1+x_2`·첨자 없는 `CO` 는 그대로.
- **검증** — `test-math-normalize` 에 17건 추가(LaTeX 구제 8: 실측 재현·통화·코드·기존 `$$`·줄 첫머리 / 화학식 9: 정체 4·오인 방지 5), 43/43. tsc 0, `npm test` 49/49.
