## 9. 인라인 LaTeX 원문 노출(사용자 피드백)

- **증상** — 카페인 구조 답변에서 `$-\text{CH}_3$`·`$=\text{O}$` 가 원문으로 보였다(한글 글꼴이라 `\` 가 `₩` 로 표시).
- **원인** — 06-24 에 통화 `$` 가 수식으로 묶이는 문제를 막으려고 단일 `$` 수식을 껐다(`singleDollarTextMath: false`, [DEV_260624 §6](../06/DEV_260624.md)). 프롬프트에 수식 표기 규칙이 없어 모델은 여전히 단일 `$` 를 쓴다.
- **수정** — 단일 `$` 수식은 꺼 둔 채, **LaTeX 명령(`\text`·`\frac` 등)이 든 `$…$` 만** `$$…$$`(인라인 수식)로 올리는 전처리 `promoteTexInlineMath`(`utils/mathNormalize.ts`)를 기존 `splitInlineDisplayMath` 앞에 끼웠다. 통화엔 역슬래시 명령이 없어 그대로다. 코드 펜스·인라인 코드 안, 공백으로 시작·끝나는 짝은 건드리지 않는다.
- **한계** — `$x^2$` 처럼 명령 없는 단일 수식은 여전히 원문이다(통화와 구별이 어려워 범위 밖).
- **화학식 정체** — 재시험에서 모델이 `$$C_8H_{10}N_4O_2$$`·`$$-CH_3$$` 로 써 렌더는 됐지만 기울임 변수체였다. 같은 줄 `$$…$$` 의 내용이 원소 기호 2개 이상 + 숫자 첨자로만 이뤄졌으면 `\mathrm{}` 으로 감싼다(`uprightChemFormulas`). `V_1`·`A_2B_3`·`x_1+x_2`·첨자 없는 `CO` 는 그대로.
- **검증** — `test-math-normalize` 에 17건 추가(LaTeX 구제 8: 실측 재현·통화·코드·기존 `$$`·줄 첫머리 / 화학식 9: 정체 4·오인 방지 5), 43/43. tsc 0, `npm test` 49/49.

## 10. 멀티턴에서 차트 출처 누락 — 키워드 가드가 라우터 판정을 덮음(사용자 피드백)

- **증상** — 배터리 비교 차트(검색·출처 5개) 다음 턴 "주요국 GDP 상위 5개국 막대 차트로 비교해줘" 가 출처 없이 기억 수치(IMF 2024 전망치)로 답했다. 같은 질문을 첫 턴으로 하면 출처(imf.org 등)가 붙었다.
- **원인** — 라우터 LLM 은 3/3 검색 on 이었다. 그 뒤 멀티턴 가드 `shouldSuppressSearchForFollowup` 가 "직전 턴 검색 + `FOLLOWUP_REF_PATTERN`(요약·정리·**비교**·방금·그거…) + 최신 요구 없음" 이면 끄는데, "비교" 한 단어에 걸렸다(로컬 판정 `억제 true`). 첫 턴은 직전 검색이 없어 가드가 돌지 않는다.
- **판단** — 단어 목록을 줄이는 게 아니라 맥락 판정을 따른다. 라우터 LLM 은 직전 답(앞 300자)을 보고, 프롬프트에 "이미 다룬 내용의 요약·가공은 false, 새 주제 통계 차트는 true" 기준이 있다. 가드의 존재 이유는 **키워드 규칙(예: "최근")이 LLM 의 false 를 뒤집어 켠 경우**를 되돌리는 것이었다.
- **수정** — 라우터가 LLM 원판정 `llmNeedsSearch`(규칙 합성 전, 없으면 null)를 state 로 넘기고(`state.ts`·`router.ts`), generator → 게이트 → `collectTextSearchSignals` 로 싣는다. 가드는 `llmNeedsSearch !== true` 일 때만 돈다 — LLM 이 검색 필요로 봤으면 덮지 않고, LLM 이 off 거나 판정이 없을 때(실패)는 기존대로 키워드 가드가 대신한다.
- **검증**
  - `test-search-policy` 8건 추가(GDP 재현 · LLM 판정 없음 대조 · 순수 가공 · "최근 검색한 내용 요약" · 배선 3), Part E 27/27. tsc 0, `npm test` 49/49.
  - 라우터 실측(유료, 18호출, 직전 턴 배터리 차트 검색): 순수 가공 6종("그거 표로 정리해줘"·"정리해줘"·"아까 결과 비교표로" 등) **LLM off 12/12**, 새 주제 3종(GDP·출생아 수 "정리"·테슬라 "비교") **LLM on 6/6**. 가드가 빠져도 가공 요청이 검색으로 새지 않는다.
