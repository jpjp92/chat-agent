# DEV_260527 — GitHub Actions 자동 PR 워크플로우 버그 수정

> 작성일: 2026-05-27

---

## 문제

DEV_260526에서 추가한 `.github/workflows/auto-pr.yml`이 dev push 후 즉시 실패.

**에러 메시지**: `This run likely failed because of a workflow file issue.`

**원인 분석**:
1. **YAML 파서 충돌** — `BODY` 변수에 빈 줄과 `---`(YAML 문서 구분자)를 인라인으로 포함해 YAML 파서가 오류 처리
2. **특수문자 `→`** — workflow name/title에 유니코드 특수문자 사용, 일부 파서에서 문제 유발 가능
3. **`--jq '.[0].number'`** — PR 없을 때 `null` 반환 → 빈 문자열 비교 불안정

---

## 수정 내역

**파일**: `.github/workflows/auto-pr.yml`

| 항목 | 수정 전 | 수정 후 |
|------|---------|---------|
| workflow name | `Auto PR (dev → main)` | `Auto PR dev to main` |
| PR title | `dev → main: ${DATE}` | `dev -> main: ${DATE}` |
| PR body 처리 | `BODY` 멀티라인 변수 → `--body "${BODY}"` | `printf > /tmp/pr_body.md` → `--body-file` |
| PR 존재 확인 | `jq '.[0].number'` → 빈 문자열 비교 | `jq length` → 숫자 비교 (`-gt 0`) |

**핵심 변경점**: 멀티라인 문자열을 YAML `run:` 블록 안에 인라인으로 두지 않고 임시 파일(`/tmp/pr_body.md`)로 분리해 `--body-file`로 전달.

---

## 최종 워크플로우 동작

1. dev 브랜치 push 발생
2. `gh pr list --base main --head dev --state open --json number --jq length` 로 오픈 PR 수 확인
3. 0이면 PR 생성 / 1 이상이면 스킵
4. PR 본문: `git log origin/main..HEAD --oneline` 최대 20개 커밋 목록
