- Vercel 에 `GEMINI_PAID_FIRST=true` · `API_KEY_TIER1` 추가 후 재배포.
- 회원 계정으로 같은 질문("오늘 원 달러 환율 알려줘")을 4개 모델에 던졌다. **전부 출처 칩 + 인용 번호 정상.**

- Vercel MCP 로 로그 조회 시도 → **403**(커넥터에 로그 권한 없음). 대시보드에서 직접 확인 필요.
