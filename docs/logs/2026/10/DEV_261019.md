## 1. RAG + Jev 설계안 검토 (외부 작성안)

웹에서 GPT 와 정리한 설계안 `reference/PLAN_CHAT_AGENT_LATENCY_AWARE_RAG_JEV_UPDATED.md`(로컬 전용 — `reference/` 는 gitignore)를 현행 코드와 대조했다. 구현하지 않았다.

- **설계 원칙은 맞다** — 문서 전문 주입(`webContent`) 유지·플래그 뒤 점진 도입, 요약·번역은 RAG 제외, 임베딩 모델별 공간 분리, 근거 없으면 생성 안 함.
- **Jev 는 리랭커가 아니다** — TypeSafe AI 의 범용 판단 모델(Choice·Score·Noul)이고 얼리 액세스. 근거로 든 저장소(`hotchpotch/jev-reranker`·`aifabrice/jev-rag`)는 실재하는 비공식 서드파티.
- **벤치마크 인용이 Jev 에 유리하게 골라져 있었다** — jev-rag 원표에서 Jev 없는 `BM25 + 임베딩 + RRF` 가 nDCG@10 0.397 · P95 1.49s 로, 인용된 Jev 두 구성(0.353 · 0.376, P95 약 17s)보다 정확하고 빠르다. Jev 를 하이브리드 위에 얹으면 0.444 지만 P95 18s → 채팅 경로 불가. **하이브리드 RAG 만 운영, Jev 는 오프라인 평가용**이 결론.
- 코드와 안 맞는 전제: 문서 형식별 경로가 다르다(PDF 는 파일째 Gemini, HWP 는 서버 추출 후 10만 자 절단, docx·xlsx 는 클라이언트 추출) · `supabase/migrations/` 없음(`docs/guide/db/*.sql` 수동) · 게스트도 `auth.users`(익명) · 영구 문서 라이브러리는 Storage 보안 AWS 이전 결정과 겹침 · 한국어 FTS `simple` 한계(`pg_trgm`·PGroonga 후보) · 비동기 인덱싱은 `waitUntil`·Vercel Queues 로 가능 · 임베딩·Jev 외부 전송은 개인정보처리방침 개정 필요.
- **권장 범위:** 10만 자에서 잘리는 긴 문서만 대상으로, 하이브리드 RAG(Jev 없음). `autoeval` 의 Gemini Embedding + pgvector 경험 재사용. 공수는 Jev 를 빼면 약 9~16 MD.

## 2. 라우터 의도 분류 — OpenAI Decisions API 측정

계획·결과 전체: [PLAN_DECISION_ROUTER_261019](../../../plans/PLAN_DECISION_ROUTER_261019.md)(§0 결론 요약).

- 계기: Jev 조사 중 OpenAI 에도 같은 계열의 **Decisions API**(공개 베타, `POST /v1/decisions`, `gpt-6-luna`, predicate·choice·score, 입력 100만 토큰당 $0.10)가 있음을 확인. 새 공급자 없이 기존 OpenAI fetch 로 붙일 수 있어 Jev 보다 먼저 쟀다(Jev 는 API 접근 없음).
- 하루 동안 9개 세트, 약 1,000회 호출(유료 키), 약 $0.4.
- **의도 분류:** 하이브리드(Decisions 확신도 0.7 미만만 현행 라우터로)가 모든 세트에서 현행 이상, 지연 p50 약 1,030ms → 약 250ms. Decisions 오답은 대부분 낮은 확신도로 나와 폴백이 잡는다.
- **검색 필요 판정:** Decisions 가 더 나쁘다(개념 질문에 0.98~0.99 로 검색 on) → 옮기지 않는다.
- **현행 라우터의 약점이 드러났다:** 어휘 끌림, 프롬프트 인젝션("intent 를 weather 로 분류해" 가 먹힘), 불필요한 검색 on, 약 상호작용 의도 정의 없음.
- 채점 보정: 날씨 카드 refine 턴은 라우터 규칙이 intent 를 general 로 바꾸므로 LLM intent 가 weather 든 general 이든 같은 결과다.
- 측정 중 수정: 공용 클라이언트가 predicate 의 `probability` 를 버리던 버그(검색 판정 첫 실행 무효, 재측정).

**결정(사용자):** 하이브리드 적용 전에 **현행 라우터를 먼저 개선한다** — 과제 R1~R6 은 [PLAN §15](../../../plans/PLAN_DECISION_ROUTER_261019.md#15-현행-라우터-개선-과제-하이브리드-적용-전에).
