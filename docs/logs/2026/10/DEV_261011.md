## 1. 발단 — 실기기 (dev, GPT-6 luna, 2.07MB 사업계획서 PDF "분석")

- 응답이 오래 걸렸고 **표 머리글 `| 세부 업무 | 수행내용` 만 두 번 찍힌 채 끝났다**(구분선 없음). 같은 PDF 재시도는 정상.
- 🔴 **답한 건 GPT 가 아니라 Gemini 2.5 였다.** OpenAI 어댑터(`toInputContent`)가 텍스트·이미지만 넘기고 PDF 는 버려서,
  generator 가 PDF 가 보이면 조용히 2.5 로 핀했다(`pinOpenAIUnsupportedMedia` + `pinUrlFileData` — GPT 모델은 `MODEL_CAPS` 에 없어 `urlFileData=false`).
  화면엔 GPT 라벨 그대로.
- 끊김 원인은 **미확정** — Vercel 로그 조회 실패(MCP 403 · CLI 400). 재시도 정상 + 300s·16384 토큰에 못 미침 → 2.5(`thinkingBudget: 0`)의 일회성 표 퇴행으로 추정.
  잘림 감지(`finishReason`·`incomplete` 가 빈 응답일 때만 검사됨)는 별도 과제로 남긴다(§4).

## 5. Google 로그인 — 계정 선택 화면에 Supabase 주소가 뜨던 것

- 증상: 로그인 시 "**ghdpnuwbvlrxmxcazzci.supabase.co**(으)로 이동", 개발자 정보의 앱 이름도 같은 주소.
- 원인: 리다이렉트 OAuth(`signInWithOAuth`·`linkIdentity({ provider })`)의 콜백이 Supabase 인증 서버라서.
  앱 이름은 Google Auth Platform 브랜딩 + **브랜드 인증** 몫(콘솔 작업, 코드 아님). 이동 주소는 커스텀 도메인(유료) 또는 **앱 안 ID 토큰**으로만 바뀐다 → 후자 선택.
- 방식: Google Identity Services 공식 버튼(`renderButton`, 팝업/FedCM) → ID 토큰 → supabase-js 2.90.1
  `linkIdentity({ provider: 'google', token, nonce })`(게스트 승계, 같은 uuid) / `signInWithIdToken`(로그인).
  nonce 는 Google 에 SHA-256 hex, Supabase 에 원문. 성공 후 **새로고침** — 리다이렉트 복귀와 같은 끝맺음을 유지(캐시·프로필 전제).
- 🔴 계정 전환(헤더)도 모달로 옮기며 발견: `guestHasData` 는 정식 사용자에게도 참 → 그대로 두면 계정 전환이 **지금 계정에 다른 Google 신원을 붙인다.**
  `shouldLinkGuest = is_guest && guestHasData && reason !== 'switch'` 로 link/signIn 기준을 한 곳에.
- 충돌(이미 다른 유저의 Google 계정): 받은 토큰을 다시 써서 바로 로그인 — 계정을 두 번 고르지 않는다. 리다이렉트로 돌아온 충돌은 기존 경로.
- 폴백: `NEXT_PUBLIC_GOOGLE_CLIENT_ID` 없음·GIS 스크립트 차단/6s 초과 → 기존 리다이렉트 버튼. 설정 전 배포해도 로그인이 깨지지 않는다.
- CSP `frame-src` 에 `https://accounts.google.com`(GIS 버튼 iframe).
