## 2. 측정이 바꾼 판단

1. **Gemini 2.5 TTS 는 stream 으로 불러도 한 덩어리로 온다** — 첫 소리 = 전체. 3.1 부터 실제 스트리밍.
2. **현행은 2000자에서 0/2 실패**였다 — "느리다"보다 큰 결함.
3. **긴 입력은 두 공급자 모두 중간을 건너뛰거나 반복한다**(끝 문장은 읽어서 표지어로는 안 잡힘). 700자 조각도 OpenAI 2/4 생략, **500자 8/8 정상** → 상한 500.
4. 🔴 **오디오 길이 판정(±3%)은 한 문장 누락을 못 잡는다.** Gemini 가 medium 의 마지막 문장을 빠뜨린 것을 전사로 처음 확인(1/7) — 프로브에 전사 기반 문장 판정 추가.
5. OpenAI 는 첫 ~0.4s 를 몰아 보낸 뒤 최대 225ms 멈춘다 → 클라이언트 지터 버퍼(OpenAI 300ms).
6. 비용(OpenAI 대시보드 역산): `gpt-4o-mini-tts` ≈ **$0.016/분**, 2000자 ≈ $0.07. Gemini 3.1 ≈ $0.14.

| | 첫 소리 | 2000자 전체 | 문장 누락 |
|---|---|---|---|
| OpenAI | 0.55~1.42s | 22~27s | 0/7 |
| Gemini 3.1 | 0.94~1.49s | 37~41s | 1/7 |

- 🔴 **정정:** "Gemini 3.8 TTS 없음"은 틀렸다 — `gemini-3.8-flash-tts`·`gemini-3.8-flash-lite-tts` 존재(모델 목록 API). 3.8 Lite: 2000자 전체 28~30s·누락 0/5 — [PLAN §4-2d](../../../plans/PLAN_TTS_STREAMING_261002.md)

→ **권장 공급자 OpenAI** — 로컬은 `TTS_PROVIDER=openai`. ⚠️ **코드 기본값은 gemini** 그대로라 배포 env 에 `TTS_PROVIDER=openai` 를 명시해야 한다(미설정 시 Gemini 무료 풀 → 10회/일/키로 실패). 전용 키 `OPENAI_API_TTS`(별도 프로젝트 hard limit — 공유 키면 상한 도달 시 GPT 채팅까지 429).

- **2026-10-04 확정:** 1순위 **Gemini 3.8 Flash Lite TTS**($6/1M, 2027 부터 $12) → 폴백 **OpenAI**(첫 바이트 전 실패만). 음량은 서버에서 보정 — 3.8 Lite 원음이 풀스케일이라 예전 1.8 이 찌그러뜨렸다 → gemini 1.0 · openai 1.4. [PLAN §9](../../../plans/PLAN_TTS_STREAMING_261002.md)

## 4. 인증·한도·예외 처리

- 라우트: `createRouteClient` → RPC `consume_tts_quota`(게스트·한도·원자적 소비) → 합성. 토큰 없음·위조 → 401, **공급자 호출 0회** 실측.
- 한도는 **글자 수**(비용 ∝ 오디오 길이). 테이블은 RLS on·정책 없음, 한도는 함수 상수, `p_chars` 1..2000 검사.
- staging 적용 확인: 비로그인 RPC/테이블 → 401(42501). 회원 재생 후 `tts_usage` 628자/2회 기록.
- 클라이언트 `TtsError(kind)` — guest·quota·auth·network·server 5종, ko/en/es/fr 문구. 버튼 툴팁·aria-label 도 4개 언어·상태별.
- 공급자 월 상한(콘솔): AI Studio Project Spend Cap, OpenAI project hard limit — 권장 $10~20.
