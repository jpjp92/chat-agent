## 2. 약 답 출처에 식약처 상세 페이지

**증상:** 약 카드 답의 출처 칩이 비어 있다. 카드 근거는 식약처 함수 결과인데 출처 칩엔 웹 검색 결과만 오른다.

**측정**(`tests/manual/probe-drug-sources.mts`, 라우트와 같은 `createStreamDispatch`, 약 4개 × GPT-5.6 luna · Gemini 3.6, TIER1):

| | GPT | Gemini |
|---|---|---|
| 카드 답 수정 전 출처 0개 | 2/3 (마그네스정만 약학정보원 1) | 3/3 |
| 수정 후 식약처 칩 | 3/3 | 3/3 |
| 카드 없는 판콜에이내복액 | 변화 없음(웹 3) | 변화 없음(웹 11) |

Gemini 는 §6(`auto`) 이전부터 0개였다 — 정리 단계 검색 강제 해제와 무관하게 약 카드 답은 대개 출처가 없었다.

**수정:** `server/agent/drug-card-urls.ts` `drugCardSources` — 최종 본문의 `json:drug` 카드 `mfds_url` 로 "식약처 의약품안전나라 · 약 이름" 출처를 만든다. nedrug 상세 주소 모양(`getItemDetail?itemSeq=숫자`)만 믿는다. `server/agent/stream-dispatch.ts` 최종(`LangGraph` chain end)에서 붙여 두 공급자 모두·DB 저장까지 같다.
- 사용자 확인(로컬, GPT-6 luna 게보린정): 웹 검색이 이미 식약처를 [1] 로 인용해 칩이 겹쳤다 → 기존 출처에 `mfds.go.kr` 도메인이 있으면(Gemini 리다이렉트는 제목) 생략.
- 재확인(로컬, GPT-6 luna 타이레놀정): 칩 `[1] 식품의약품안전처` · `connectdi.com` 두 개 — 식약처 칩 생략 확인.
- chat-agent-dev 확인(GPT-5.6 luna): 타세놀정(웹 인용 없음) → `식약처 의약품안전나라 · 타…` · `connectdi.com` 칩. 이부센연질캡슐은 카드 없이 약학정보원 [1] 만(설계대로).
- 출처가 생기면 다음 턴 `lastTurnSearched` 가 참이 돼 "직전 답 번복 금지" 규칙이 실린다 — 식약처 공식 데이터라 맞는 동작으로 본다.
