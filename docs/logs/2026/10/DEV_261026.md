## 1. 길게 누르기 메뉴(복사·수정)가 다음 턴 메시지에 가려짐

증상(chat-agent-dev, iPhone): 사용자 프롬프트를 길게 누르면 뜨는 복사·수정 메뉴 위로 다음 AI 답 글자가 비쳐 보인다.

원인: 메뉴가 `fixed z-[9999]` 지만 메시지 트리 안에 렌더된다. 메시지 루트의 `animate-in fade-in` 이 쌓임 맥락을 만들어 z-index 가 그 메시지 안에서만 비교되고, 뒤에 그려지는 다음 메시지가 위로 온다.

수정: 메뉴를 `createPortal(…, document.body)` 로 뺀다(`SourceBar`·`DrugRenderer` 와 같은 방식) — `components/ChatMessage.tsx`. 바깥 탭·스크롤 닫힘은 그대로.

## 2. `neural link의 bci 최근연구 동향 알려줘` → 논문 검색

증상: GPT 는 arXiv 2018 논문 1편, Gemini 는 "찾을 수 없음". 사용자가 원한 것은 회사가 무엇을 하고 있는가(임상·FDA 지정·발표)였다 — 두 번째 턴 웹 검색 답은 정상.

원인: 폴백 규칙(`intent-rules.ts` `연구…알려`)이 아니라 라우터 LLM 정의. `paper_search` 정의가 "연구 결과 알려줘" 를 논문 요청으로 예시해, "연구" 가 들어간 회사 근황 질문이 논문으로 갔다(→ `paper_source` arxiv).

수정(정의, 키워드 규칙 아님): `server/agent/nodes/router.ts` `paper_search` 에 두 번째 반례 — 주어가 특정 조직·회사·제품·인물이고 **그들이 무엇을 하는지**를 묻는 질문은 general. 그들의 **논문**을 찾는 요청과 행위자 없는 분야 전반 질문("BCI 최근 연구 동향")은 paper_search 유지. 판단 질문: 뉴스·공식 페이지로 충족되는가, 논문만 되는가.

튜닝 세트 `ROUTER_ORG_ACTIVITY`(6문장, `tests/manual/router-cases.mts`) · `probe-router-gpt.mts --set=org`.
