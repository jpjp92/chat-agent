## 2. 🔴 A — 어제 쓴 보안 검토가 레포의 실측을 덮어쓰고 있었다

### 2.1 무엇이 충돌했나

[TODO.md §보안](../../../TODO.md) 은 2026-08-29 에 **실측과 함께** 이렇게 적어뒀다.

> ✅ **SSRF 는 생각보다 낫다(실측)** — … **숫자 IP 우회도 막힌다** — WHATWG `new URL()` 이 `http://2130706433/` 을 `127.0.0.1` 로 정규화해주기 때문(정규식 덕이 아니라 **파서 덕**이다)

[보안 검토 초판](DEV_260903_SECURITY_REVIEW.md) 은 같은 대상을 놓고 정반대로 적었다 — *"10진 정수 표기 `http://2130706433/` → 통과"*.

**Node 로 결판냈다.**

```
http://2130706433/    → hostname 127.0.0.1        ✅ 차단   ← TODO 가 맞다
http://0x7f000001/    → hostname 127.0.0.1        ✅ 차단
http://0177.0.0.1/    → hostname 127.0.0.1        ✅ 차단
http://2852039166/    → hostname 169.254.169.254  ✅ 차단
```

**TODO 가 맞고 검토가 틀렸다.** 검토는 "문자열 매칭이니 표기법 우회가 통한다"는 **일반론**을 적었고, TODO 는 **직접 재본 값**을 적었다.

### 2.2 그런데 실측하다 TODO 도 못 본 게 나왔다

같은 실측에서 IPv6 를 넣어보니:

```
http://[::1]/                  → hostname [::1]              ❌ 통과
http://[fd00::1]/              → hostname [fd00::1]          ❌ 통과
http://[fe80::1]/              → hostname [fe80::1]          ❌ 통과
http://[::ffff:127.0.0.1]/     → hostname [::ffff:7f00:1]    ❌ 통과
```

🔴 **정규식이 IPv6 를 막으려고 넣은 4개 항목(`::1`·`fc..`·`fd..`·`fe80:`)이 전부 죽은 코드다.** `hostname` 이 IPv6 를 **대괄호째** 돌려주는데 정규식은 `^` 앵커라 `[` 로 시작하는 문자열에서 `::1` 을 매치할 수 없다.

```js
RE.test("::1")    // true   ← 작성자가 의도한 값
RE.test("[::1]")  // false  ← 실제로 들어오는 값
```

**이것 때문에 TODO 에 열려 있던 수정 계획이 무효다.** *"IPv4-mapped IPv6(`::ffff:*`) 를 `SSRF_BLOCK` 에 추가"* — 추가해도 대괄호가 남아 `^` 가 여전히 막는다(실측 확인). **대괄호를 벗기는 1줄이 선행돼야 기존 4항목이 비로소 동작한다.**

### 2.3 우선순위가 틀렸던 것 — 6개를 2개로 봤다

TODO 는 무인증 라우트를 **6개**로 세어뒀다: `fetch-url`·`proxy-image`·`showtimes`·`speech`·`summarize-title`·`sync-drug-image`. **검토는 앞의 둘만 보고 "SSRF 가 1순위"라 답했다.** 확인해보니:

[lib/limits.ts](../../../../lib/limits.ts) 가 밝힌 이 앱의 실제 위협 모델은 *"무료 Gemini 키의 일일 할당량(RPD) 방어 — 소진되면 소유자 본인이 24시간 못 쓴다"* 다. **거기에 직결되는 건 이 둘이고, TODO 는 이미 🔴 를 붙여 적어뒀다.**

### 2.4 ⚖️ 교훈 — 검토 대상이 코드여도 먼저 읽을 것은 레포의 기록이다

세 오류(A1·A2·A3)는 원인이 하나다. **레포가 자기에 대해 이미 적어둔 문서를 읽지 않고 코드부터 봤다.**

- A1 — 반증된 주장을 **다시 적었다**. 새 문서가 기존 실측을 덮어쓰는 오답이 됐다.
- A2 — 이미 세어둔 6개를 2개로 보고 **더 급한 항목을 3턴 동안 밀어냈다.**
- A3 — 기존 계획이 왜 안 통하는지는 **실측해야 나왔는데**, 실측할 생각을 한 건 문서 충돌을 발견한 뒤였다.

🔴 이 레포는 **자체 정정 문화가 이미 강하다**(⚖️ 표기, §5 의 60s 사례). 그 축적을 안 읽으면 새 문서가 오히려 품질을 떨어뜨린다.
