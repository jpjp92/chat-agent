# DEV_260530 — 기본 모델 3.5 Flash로 변경

> 작성일: 2026-05-30

---

## 1. 변경 내용

UI 모델 선택 드롭다운에서 Gemini 3.5 Flash를 기본(main) 선택 모델로 변경.

---

## 2. 수정 파일

### `src/lib/models.ts` (클라이언트)

- `DEFAULT_CHAT_MODEL`: `CHAT_MODELS.FLASH` → `CHAT_MODELS.FLASH_3_5`
- `CHAT_MODEL_OPTIONS` 순서 변경: 3.5 Flash → 2.5 Flash 순으로 재배치
  - 드롭다운 첫 번째 항목이자 `CHAT_MODEL_OPTIONS[0]` 폴백도 3.5 Flash

### `server/models.ts` (서버)

- `DEFAULT_CHAT_MODEL`: `SERVER_MODELS.FLASH` → `SERVER_MODELS.FLASH_3_5`
- `api/chat/route.ts`에서 모델 미지정 시 사용하는 서버 폴백도 통일

---

## 3. 동작 변경

| 상황 | 변경 전 | 변경 후 |
|---|---|---|
| 첫 방문 (localStorage 없음) | 2.5 Flash 기본 선택 | 3.5 Flash 기본 선택 |
| 드롭다운 첫 번째 항목 | 2.5 Flash | 3.5 Flash |
| 서버 모델 폴백 | 2.5 Flash | 3.5 Flash |
