# DEV_260612

> 영화 통합(86a2d68) 배포 후 **프로덕션 전용 라우팅 버그** 진단·수정 + README 반영. 통합 본류: [DEV_260611](DEV_260611.md) §6.

## 1. 증상 — 프로덕션에서 영화 질의가 일반 검색 응답으로 폴백

배포된 Vercel 앱에서 "영화정보" 질의 시 `json:movie` 카드 대신 **Google Search two-track의 일반 표 응답**(상영작/개봉예정 표) 반환. **로컬은 정상** — 카드 잘 뜸.

런타임 로그의 결정적 라인:

```
[LangGraph] Semantic Router LLM failed, falling back to heuristics: 400
[LangGraph] Router decided: intent=general, needsSearch=true
[LangGraph] Two-track enabled: stage1(2.5+search) -> stage2(3.5+minimal)
```

## 2. 진단 — 2단 라우팅 구조의 빈틈 노출

라우팅은 **1차 LLM 라우터(flash-lite) → 실패 시 2차 정규식 폴백** 구조.

| 환경 | 1차 LLM 라우터 | 2차 정규식 | 결과 |
|------|------|------|------|
| 로컬 | ✅ 성공 → `movie_search` | (안 탐) | 카드 정상 |
| 프로덕션 | ❌ **400 실패** | "영화정보" 미매칭 | `general`+검색 폴백 |

- "정규식 보강 없이도 로컬은 잘 됐다"의 이유: 로컬은 폴백 자체를 안 탔기 때문. 정규식은 LLM 실패 시에만 노출되는 안전망이라, 약국·법률처럼 키워드가 견고한 intent는 그동안 폴백으로도 버텼지만 영화 정규식의 빈틈("영화+정보" 조합 부재)이 이번에 드러남.
- **400의 정체(추정)**: 로컬 `.env` 키 12개를 flash-lite REST로 전수 점검 → **전부 OK**. 프로덕션(Vercel Sensitive 키셋, pull로 대조 불가)에 죽은 키가 섞여 있을 가능성. 결정적 구조 버그 — **Gemini는 무효 API 키를 401이 아닌 `400 API_KEY_INVALID`로 반환**하는데, 기존 코드는 401/403만 `markKeyInvalid` 처리 → **죽은 키가 로테이션에 영구 잔존**하며 호출을 무작위 오염(이번엔 라우터가 죽은 키, 제너레이터가 정상 키를 뽑아 검색은 동작). 기존 라우터 로그는 status만 찍어 메시지 확인 불가했음.

## 5. ★ 영화 멀티턴 후속 질문 (클라이언트 캐리 하이브리드)

### 증상
턴1 "영화정보"→카드(정상). 턴2 "메가박스에만 상영하는 경우 있어?"→**또 같은 카드**. 두 원인:
1. **재라우팅**: 후속 질문에 체인명("메가박스")·"상영"이 들어가 정규식이 또 `movie_search`로 분류 → fast-pass로 무조건 카드. movieTool은 region만 보므로 턴1과 동일 카드.
2. **데이터 부재(근본)**: 클라이언트 페치 구조라 상영표가 브라우저에만 있고 LLM 컨텍스트엔 `json:movie{region,defaults}`만 저장 → 비교/필터 질문을 답할 데이터가 없음.

### 해결 — 클라이언트 캐리 하이브리드
사용자 제안("가져온 카드정보 요약 → 없으면 검색")대로, 카드가 **이미 가져온 데이터를 재사용**(후속 턴 추가 지연 0, 드롭다운 변경 지점도 반영).

| 단계 | 동작 |
|------|------|
| 턴1 | 현행 카드 (변경 없음) |
| 적재 | `MovieRenderer`가 체인별 조회 완료 시 화면 상영표를 `lib/movieContext.ts` 클라 스토어에 적재(키=chainKey, 최신 카드로 덮어씀) |
| 전송 | `useChatStream`→`geminiService`가 다음 메시지에 `movieContext`(컴팩트 텍스트) 동봉(webContent 선례) |
| 라우팅 | `router`: 카드 존재(movieContext)+질문형(`MOVIE_FOLLOWUP_QUESTION`: `?`·비교·"~만"·제일·있어 등)이면 `movie_search`→**general 재분류**(카드 재생성 차단). 새 지역 요청("홍대 영화 상영시간표")은 질문형 아니라 그대로 카드 |
| 답변 | `generator`: general+movieContext면 시스템 프롬프트에 상영표+규칙 주입 → 화면 데이터로 요약 답변. **needsSearch=false 강제**(검색 켜면 그 데이터 무시하고 또 일반 표 냄 = 바로 그 버그). 데이터에 없는 정보(줄거리·평점 등)는 없다고 밝히고 검색/재조회 안내 |

### 신규/수정 파일
- 신규 `lib/movieContext.ts` — 클라 스토어(`setChainShowtimes`/`getMovieContextText`/`hasMovieContext`).
- 배관: `MovieRenderer.tsx`(적재)·`useChatStream.ts`(전송, 현재 대화에 카드 있을 때만)+`geminiService.ts`(전송)·`state.ts`(`movieContext`+`movieFollowup` 필드)·`app/api/chat/route.ts`(주입).
- 라우팅/답변: `router.ts`(2-tier 후속 가드 → `movieFollowup` 산출 + needsSearch off)·`generator.ts`(`movieFollowup` 턴만 movieContext 주입).

### 검토 보강 (self-review)
- **단일 `movieFollowup` 플래그**(state)로 일원화: 기존 generator 주입 조건(`movieContext && intent==='general'`)이 너무 넓어 카드 본 뒤 **무관한 general 질문("날씨")에도 상영표 주입 + LLM이 직접 general로 본 후속은 검색 off 누락** 문제가 있었음. 라우터가 두 경로를 모두 포착해 플래그 산출 → generator·needsSearch가 그 플래그만 봄.
  - 2-tier: ① `movie_search`+질문형(`MOVIE_FOLLOWUP_QUESTION`, 물음표 포함) → general 재분류 ② 이미 `general`인데 영화 맥락어(`MOVIE_CONTEXT_TERMS`, **물음표 단독 제외** → "날씨 어때?" 오발 방지) → 플래그만.
- **stale 누출 차단**: `movieContext` 스토어는 모듈 전역이라 대화 전환 시 안 비워짐 → `useChatStream`이 **현재 대화에 `json:movie` 카드가 있을 때만** 전송하도록 게이트.

### 상영표에 없는 정보 → 웹 검색 전환 (offer→confirm→search)
후속 질문이 상영표에 없는 정보(줄거리·평점·예매율·관객수·장르)를 요구하면, 모델이 **"상영표엔 없어요" + "웹에서 검색해 드릴까요?"** 로 물어보고(generator 규칙), 사용자가 동의하면 **그 턴은 검색 ON**으로 전환. 안 그러면 후속=검색off라 "응"도 또 off되는 루프에 빠짐.
- 라우터에 2경로 추가(가드보다 우선): ① **명시적 검색요청**(`EXPLICIT_SEARCH_REQUEST`: 검색·찾아봐·구글·웹에서…) ② **제안 후 동의**(직전 봇 메시지가 `SEARCH_OFFER_MARKER`="웹에서 검색해 드릴까요?" + 현재 메시지가 `AFFIRM`: 응·ㅇㅇ·네 부탁해요·그래 찾아줘…) → `forceSearch=true`, `intent=general`, movieFollowup 아님(=movieContext 미주입, 검색으로 답).
- **버그 발견·수정(시뮬)**: `AFFIRM`에 `\b`를 쓰니 한글 뒤 워드경계 미성립으로 "응"이 매칭 실패 → lookahead `(?=[\s!.~?,…]|$)`로 교체. 오발 방지: "예매하고 싶어"·"어제 영화"는 AFFIRM 미매칭 확인.

### 검증
- `tsc --noEmit` 클린, `npm run build` ✓.
- 라우팅 시뮬(2-tier): "메가박스에만 있어?"·"제일 빠른 시간은?"·"CGV랑 비교"·"좌석 많은 영화 추천"→general+followup+검색off / "오늘 날씨 어때?"·"파이썬 코드 짜줘"→general+followup**없음**+정상검색(주입 안 됨) / "홍대 영화 상영시간표"·"강남 메가박스 보여줘"→movie_search(새 카드). 카드 없는 턴1은 가드 미발동. ✓
