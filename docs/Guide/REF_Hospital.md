# Hospital-Viz: Test Prompt Guide

Reference prompts for testing the `json:hospital` renderer and the hospital search pipeline (건강보험심사평가원 병원정보서비스 API).

> ⚠️ API 키 만료일: **2028-05-07** (PHARM_KEY 공용 — 재신청 필요)

---

## Renderer Schema

```json
{
  "query": "강남구 내과",
  "count": 10,
  "hospitals": [
    {
      "name": "강남세브란스병원",
      "address": "서울특별시 강남구 언주로 211",
      "phone": "02-2019-3114",
      "url": "https://www.yuhs.or.kr/hospitals/gangnam",
      "type": "상급종합",
      "doctor_count": 850,
      "established": "19710101",
      "lat": 37.4924,
      "lon": 127.0341
    }
  ]
}
```

**종별 타입 값**: `상급종합` · `종합병원` · `병원` · `의원`

- "강남구에서 의사 많은 병원 알려줘" — 의사수 내림차순 정렬 기본 적용

## Tips

- **종별 뱃지 색상**: 상급종합(보라) · 종합병원(인디고) · 병원(하늘) · 의원(슬레이트)
- **전화번호**: 모바일 `tel:` 링크 / 데스크톱 클립보드 복사 + Toast
- **카카오맵 링크**: 위도/경도 핀 링크
- **정렬**: 의사수 내림차순 → 가나다순
- **CITY_TO_SIDO 매핑**: "전주시" → 전라북도, "청주시" → 충청북도 자동 변환
- **dong_name 필터**: HIRA API에 읍면동 필터 없음 → `addr` 텍스트 클라이언트 필터링
- **홈페이지 버튼**: `url` 필드가 있을 때만 표시
