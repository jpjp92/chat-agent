# DEV 2026-05-13

## 1. 동물병원 상세정보 보강 방향 정리

### 배경

- 행정안전부 동물병원 API는 현재 카드에 필요한 기본 위치 정보 중심으로 활용 중.
- 실제 반환/표시 가능한 정보는 병원명, 주소, 전화번호, 영업상태, 인허가일자 정도.
- 운영시간, 휴무일, 홈페이지, 리뷰, 진료 특화 정보는 공공 인허가 데이터만으로 안정적으로 제공하기 어려움.

### 검토

- 웹검색으로 병원별 상세정보를 보강할 수는 있음.
- 다만 동물병원 결과 3~10개 각각에 대해 자동 웹검색을 붙이면 응답 지연이 크게 증가할 수 있음.
- 현재 `vetTool`은 fast-pass로 `json:vet` 블록을 바로 스트리밍하는 구조라, 자동 보강을 넣으면 빠른 카드 렌더링 장점이 약해짐.
- 웹검색 결과는 병원별 최신성/정확도 편차도 있어, 기본 카드 결과를 대체하기보다 보조 정보로 다루는 것이 적절함.

### 방향

- 기본 동물병원 검색은 지금처럼 공공데이터 기반으로 빠르게 유지.
- 자동 웹검색 상세 보강은 기본 검색 경로에 넣지 않음.
- 상세정보가 필요한 경우 다음 방식 중 하나로 별도 검토:
  - 사용자가 특정 병원을 선택했을 때 1곳만 웹검색으로 보강.
  - 카드에 `상세 정보 찾기` 액션을 추가해 수동 실행.
  - 자동 보강이 필요하면 상위 1~3개까지만 제한하고, 실패해도 기본 카드 결과는 유지.
- 우선순위는 낮음. 현재는 동 단위 검색 보정과 빠른 기본 결과 품질이 더 중요함.
