## 1. main 브랜치 배포 에러 해결 — "No Next.js version detected"

### 현상

Vercel이 `main` 브랜치를 배포하면서 아래 에러 발생:

```
Warning: Could not identify Next.js version, ensure it is defined as a project dependency.
Error: No Next.js version detected. Make sure your package.json has "next" in either "dependencies" or "devDependencies".
```

### 원인

이전 세션에서 `dev` 브랜치에서 Next.js 마이그레이션 전체를 완료했지만, `main`에는 URL 버그 fix 2건만 cherry-pick (`81bb3bd`)된 상태였다. 결과적으로:

| 브랜치 | 상태 |
|--------|------|
| `dev` | Next.js App Router 완전 전환, `package.json`에 `next ^16.2.6` 포함 |
| `main` | `package.json` Vite 스크립트 + `next` 미포함, `index.html`·`vite.config.ts` 잔존, `app/` 디렉토리 없음 |

Vercel 프로젝트는 프레임워크 preset = Next.js이므로 `main` 배포 시 `next`를 찾지 못해 빌드 실패.

### 수정 — `dev` → `main` 전체 머지

```bash
git checkout main
git merge dev --no-ff
git push origin main
```

**머지로 반영된 주요 변경 (52개 파일)**:

| 변경 | 내용 |
|------|------|
| `package.json` | `next ^16.2.6`, `eslint-config-next`, `server-only` 추가 / `vite`, `terser`, `@vercel/node` 제거 |
| `app/` 디렉토리 | `layout.tsx`, `page.tsx`, `globals.css`, 12개 Route Handlers |
| `next.config.ts` | 신규 추가 |
| `index.html`, `vite.config.ts` | 삭제 |
| `api/*.ts` (12개) | 삭제 (구 Vercel Functions — app/api/ Route Handlers로 대체) |
| `vercel.json` | `functions` 블록 제거 |

**결과**: Vercel 빌드 성공, 전체 기능 정상 동작 확인.
