# 검색 라우팅 — 동작과 테스트 질의

> 최종 갱신: 2026-09-03
> 근거 로그: [DEV_260902_SEARCH_ROUTING](../logs/2026/09/DEV_260902_SEARCH_ROUTING.md) · 설계: [PLAN_SEARCH_POLICY_260815](../plans/PLAN_SEARCH_POLICY_260815.md)

"검색이 켜지는가"와 "논문 카드로 갈 것인가"는 서로 다른 판정인데 **증상이 같다** — 사용자는
둘 다 *"검색해달라고 했는데 안 했다"* 로 겪는다. 그래서 한 문서에서 함께 본다.

---

## 1. 현재 동작

### 1-1. 검색 on/off — 계층으로 정한다

아무도 덮어쓰지 않는다. 각 게이트가 **신호를 제출**하고 선언된 tier 가 승자를 정한다
([search-policy.ts](../../server/agent/search-policy.ts)).

| Tier | 낼 수 있는 판정 | 근거 |
|---:|:---:|---|
| 400 `HARD_CONSTRAINT` | off만 | **Gemini 턴에서만.** 이미지와 grounding 을 한 요청에 못 담는다 |
| 300 `USER_EXPLICIT` | on만 | 사용자가 검색·출처를 명시 요청 |
| 200 `CONTEXT_GROUNDED` | off | URL 본문·첨부문서·영상 자막이 이미 근거 |
| 100 `CLASSIFIER` | on/off | 룰·라우터 LLM·멀티턴 가드·`medical_qa` 강제 |
| 0 `DEFAULT` | on | 검색 누락 방어 |

⚠️ **400 은 공급자 제약이지 정책이 아니다.** OpenAI Responses 는 `input_image` 와
`web_search` 를 함께 보내므로 그 경로에서는 신호 자체가 나오지 않는다(`provider: 'openai'`).

⚠️ **400 이 사는 범위는 "대화 내내"가 아니라 첨부 직후 턴이다.** 히스토리는 첨부를 최근
`mediaWindow`(기본 3) **개**까지만 미디어로 싣고 그 밖은 `[Attached File: …]` 텍스트로 강등한다.
강등되는 순간 `[History] 첨부 미디어 → 텍스트 강등` 로그가 찍힌다 — 판정이 뒤집힌 이유는 거기서 읽는다.

### 1-2. 이미지를 빼고 검색을 켜는 탈출구 (Gemini 전용)

`shouldDropImageForSearch`([search-signals.ts](../../server/agent/search-signals.ts)) —
**이번 턴에 새 이미지가 없고**, 히스토리에 이미지가 있고, 검색 신호가 있으면 미디어를 빼고 검색을 켠다.

- 대상: `general` · `medical_qa`
- **제외: 렌더러 4종**(`astronomy`·`biology`·`chemistry`·`physics`·`data_viz`) — 히스토리 이미지가
  답의 **대상**일 수 있고(`이 사진 속 분자 구조 그려줘`) tier 200 으로 어차피 off 다

### 1-3. 논문이냐 소프트웨어 산출물이냐

3층으로 막는다. 위가 뚫리면 아래가 받는다.

| 층 | 무엇 | 어디 |
|---|---|---|
| ① 프롬프트 | *"받고 싶은 게 문헌인가 산출물인가"* 부정 앵커 | [router.ts](../../server/agent/nodes/router.ts) |
| ② 규칙 | `resolvePaperArtifactIntent` — 산출물 어휘 O + 논문 어휘 X → `general` | [intentRules.ts](../../server/agent/intentRules.ts) |
| ③ 종합단계 웹검색 | 논문 카드 + 명시 검색 요청이면 조회 **후** 웹을 붙인다 | OpenAI: `withExplicitSearchFollowup` · Gemini: `shouldAddWebSearchToPaperFollowup` |

⚠️ ③ 은 **조회가 끝난 뒤에만** 붙는다. 1차 호출에 도구를 둘 주면 `forceDomainTool`
(`allTools.length === 1`)이 풀려 모델이 논문 도구를 아예 안 부를 수 있다.

### 1-4. arXiv 검색어는 두 곳에서 정해진다

카드가 무관한 논문으로 채워지면 라우팅이 아니라 **검색어**를 먼저 본다.

| 어디 | 무엇 | 왜 거기인가 |
|---|---|---|
| 도구 설명 (`search_arxiv.query`) | 사용자가 말하지 않은 **범용어를 덧붙이지 않는다** — 단 `graph neural network` 처럼 그 자체가 개념이면 통째로 | 코드로 범용어를 걸러 봤더니 복합 개념 질의가 무너졌다. 가르는 건 문맥이고 문맥은 모델만 안다 |
| `buildArxivQueryPlan` | 불용어가 섞였으면 **제목 필드(`ti:"…"`)를 먼저** 치고 0건이면 AND 조립으로 폴백 | 제목은 키워드 묶음이 아니다. `Attention Is All You Need` 는 셋이 불용어라 AND 로는 원 논문이 안 나오고, `all:"…"` 로는 2위라 `limit:1` 에서 사라진다 |
| `repairPaperMarkerLinks` | `[N](url)` 의 번호를 **URL 로 교정**한다(카드 밖 논문이면 마커를 뗀다) | 번호가 범위 안이면서 틀릴 수 있다 — 범위 검사로는 못 잡는다. grounding 링크는 손대지 않는다 |

⚠️ 한 번에 합치는 `all:"…" OR (AND 조립)` 은 **안 된다** — 관련도 정렬이 구절 일치를 우대하지
않아 원 논문이 여전히 상위 밖이다(실측). 그래서 순차 폴백이다.

⚠️ **관련도 5/5 가 "좋은 답"은 아니다.** arXiv `sortBy=relevance` 는 인용수·영향력을 안 봐서,
`transformer` 상위 5건에 원 논문이 없다. "대표 논문"류 질의는 카드보다 웹 grounding 이 나을 수 있다.

## 2. 테스트 질의

```bash
npm run dev        # 또는 npx vercel dev
```

각 절이 **무엇을 보는지**가 다르다. `[H]` 는 회귀 하니스가 이미 덮는 항목이고,
표시가 없으면 **사람이 화면으로 봐야 하는 것**이다(멀티턴·카드 렌더·모델 전환).

### A. 소프트웨어 산출물 — 논문 카드가 뜨면 안 된다

| 질의 | 확인할 것 |
|---|---|
| 클로드 skills 관련된 레포 검색 | 🔴 **이 결함의 원본 질의.** arXiv 카드 없이 웹 검색으로 답하는가 `[H]` |
| MCP 서버 오픈소스 프로젝트 검색 | `[H]` |
| rag 라이브러리 추천해줘 | `[H]` |
| langchain 저장소 어디야 | 축약형 아닌 `저장소` 도 마찬가지 |
| github 에서 claude skills repo 찾아줘 | 영문 표기 `[H]` |
| 단백질 구조 예측 깃허브 저장소 찾아줘 | **주제가 의생명이어도** 산출물 요청이면 카드 없음 `[H]` |
| 클로드 skills 관련된 자료 검색 | `자료` 는 산출물 어휘가 아니다 — 그래도 논문 카드는 아니어야 한다 |

### B. 진짜 논문 요청 — 카드가 유지돼야 한다 (A 의 회귀 가드)

**A 만 보고 고치면 여기가 깨진다.** 같은 단어가 주제로만 등장하는 경우다.

| 질의 | 확인할 것 |
|---|---|
| 깃허브 코파일럿 생산성 논문 있나 | 🔴 **프롬프트 1차 문안이 이걸 죽였다.** `깃허브` 는 연구 대상이지 요청 대상이 아니다 `[H]` |
| 오픈소스 라이선스 관련 연구 있어? | 같은 모양 — `연구` 가 있으면 논문이다 `[H]` |
| 트랜스포머 논문 찾아줘 | arXiv 유지 `[H]` |
| 확산모델 관련 연구 있어? | `논문` 이라는 단어 없이도 arXiv |
| 고혈압 임상시험 결과 알려줘 | PubMed 유지 `[H]` |
| 장내 미생물과 우울증 관련 논문 찾아줘 | PubMed 유지 |

### C. 이미지 + 검색 — 공급자에 따라 갈린다

**모델을 바꿔가며 본다.** 이게 이 절의 전부다.

| 순서 | 입력 |
|---|---|
| 1턴 | 이미지 첨부 + `이 이미지 설명해줘` |
| 2턴 | `저기 저장소 검색해서 확인해봐` |

| 선택 모델 | 기대 |
|---|---|
| GPT-5.4 mini / GPT-5.6 Luna | 🔴 **검색이 붙는다.** *"실시간 검색 없이 학습된 지식으로만"* 이 나오면 회귀 `[H]` |
| Gemini 3.6 / 3.7 | 검색이 붙는다 — 이미지를 빼는 탈출구가 발동(`[LangGraph] 이미지+검색 가드` 로그) |

대조군도 함께 본다:

| 2턴 입력 | 기대 |
|---|---|
| `표로 정리해줘` | 검색 **OFF** — 명시 요청이 아니므로 이미지를 지키는 게 맞다 `[H]` |
| 이미지 첨부 + `이거 검색해서 확인해줘` (같은 턴) | Gemini 는 **OFF** 가 정상 — 이번 턴 이미지가 질문 대상이다 `[H]` |

### D. `medical_qa` 검색 강제 (2026-09-02 신규)

| 순서 | 입력 | 기대 |
|---|---|---|
| 1턴 | 약 사진 첨부 + `이 약 뭐야` | 알약 식별 |
| 2턴 | `이 약 부작용 최신 자료 검색해서 알려줘` | 🔴 **출처 칩이 붙는다.** 예전엔 400 에 눌려 출처 없이 답했다 `[H]` |

### E. 멀티턴 경계 — 턴이 지나면 판정이 바뀐다

같은 요청인데 **턴 거리만으로** 갈린다. 정상 동작이지만 헷갈리는 지점이라 명시한다.

| 순서 | 입력 |
|---|---|
| 1턴 | 이미지 + `이 이미지 설명해줘` |
| 2턴 | `고마워` (잡담으로 한 턴 태운다) |
| 3턴 | `저기 저장소 검색해서 확인해봐` |

3턴에서 서버 로그에 `[History] 첨부 미디어 → 텍스트 강등 (mediaWindow 3 밖)` 이 찍히고,
그 이후로는 Gemini 에서도 400 이 아예 나오지 않는다. **로그가 안 찍히면** 창 계산이 바뀐 것이다.

### F. 논문 카드 + 명시 검색 요청 (③층)

라우터가 미끄러졌을 때의 2차 방어라, **일부러 논문 의도를 태우고** 검색을 요구한다.

| 순서 | 입력 | 기대 |
|---|---|---|
| 1턴 | `트랜스포머 논문 찾아줘` | arXiv 카드 |
| 2턴 | `이 주제 최신 소식도 웹에서 검색해줘` | 카드는 그대로 두고 **웹 출처가 함께** 붙는가 |

대조군 — 불필요한 웹 호출이 붙으면 안 된다:

| 2턴 입력 | 기대 |
|---|---|
| `두번째 논문 설명해줘` | 웹 없음. 화면 카드로만 답한다 `[H]` |
| `아까 검색한 거 정리해줘` | 웹 없음 — 과거참조는 새 검색 요청이 아니다 `[H]` |

### H. arXiv 검색어 품질 (2026-09-03 신규)

카드 **내용**을 본다 — 라우팅이 맞아도 여기서 망가진다.

| 질의 | 확인할 것 |
|---|---|
| 트랜스포머 논문 찾아줘 | 도구 입력이 `transformer` 인가(`transformer neural network` 면 회귀). 상위 5건이 전부 트랜스포머 논문인가 |
| Attention Is All You Need | 🔴 **원 논문 1706.03762 이 카드에 있는가.** 구절 폴백이 빠지면 사라진다 `[H]` |
| graph neural network 논문 | 그래프 **이론** 논문이 오면 회귀 — 복합 개념이 쪼개진 것이다 `[H]` |
| 교량 내진보강 논문 | 0건이 정답(arXiv 가 토목을 거의 안 싣는다). 빈 카드 대신 산문이 나오는가 |
| 가장 유명한 트랜스포머 논문은? | ⚠️ 카드가 원 논문을 못 집을 수 있다 — arXiv 관련도 정렬의 한계. 웹 grounding 으로 답하면 정상 |
| `a survey on medical image segmentation methods` (도구에 직접) | 구절 폴백의 **비용 케이스**. ~3초 추가되며 거의 전부 arXiv 간격 대기다 |

⚠️ **한국어 질의로는 폴백을 못 잰다.** 모델이 영어로 옮기면서 기능어가 떨어져 불용어가 사라진다
(`의료 영상 분할을 위한 딥러닝 논문` → `deep learning medical image segmentation`, 계획 1개).
비용을 재려면 도구를 직접 호출해야 한다.

⚠️ **카드 유무를 화면 색으로 판단하지 말 것.** 답이 정확해도 카드 없이 웹 grounding 으로 나온
것일 수 있다 — 근거 칩이 `json:paper` 카드인지 출처 칩인지로 갈린다(실제로 이걸로 한 번 속았다).
서버 로그 `[OpenAI] local tool "search_arxiv" ←` 가 확실한 판별점이다.

> 실측 도구: `npx tsx tests/manual/live-arxiv-query.mts [질의]` — **총건수가 아니라 상위 5건의
> 제목**을 읽을 것. 관련도 숫자는 정규식 근사라 회귀를 숨긴 적이 있다.

### G. 회귀 — 기존 의도를 잠식하지 않는가

| 질의 | 가야 할 곳 |
|---|---|
| 오늘 서울 날씨 | `weather` — 카드 |
| 퀵소트 구현해줘 | `general` · 검색 OFF (코드 작성) |
| 인상주의 회화 연구 찾아줘 | 카드 없음 — 두 DB 밖 |
| 서울 날씨 검색해줘 | 날씨 카드. 논문 ③층이 발동하면 안 된다 `[H]` |
| 방금 알려준 거 표로 정리해줘 | 검색 OFF — 멀티턴 가드 `[H]` |
| 그럼 모티프 모델 구체적으로 찾아서 정리해보자 | 검색 **ON** — `정리` 에 걸려 억제되면 회귀 `[H]` |

🔴 **하니스가 덮지 못하는 것**: 라우터 LLM 의 실제 판정(A·B 의 프롬프트 층), 카드 렌더,
멀티턴 UI, 모델 전환. A·B 의 프롬프트 층은 `tests/manual/live-paper-routing.mts` 로 실모델을 태운다.

⚠️ **프롬프트 수정은 하니스로 안 잡힌다.** 문자열 변경이라 회귀 하니스가 못 본다 —
A 만 고치고 B 를 안 보면 조용히 깨진다(실제로 한 번 그렇게 깼다). 프롬프트를 만졌으면
**A 와 B 를 같은 실행에서** 재야 한다.
