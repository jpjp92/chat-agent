# Pharmacy-Viz: Test Prompt Guide

Reference prompts for testing the `json:pharmacy` renderer and the pharmacy search pipeline (공공데이터포털 전국 약국 API).

> ⚠️ API 키 만료일: **2028-05-06** (PHARM_KEY — 재신청 필요)

---

## Renderer Schema

```json
{
  "query": "강남구 약국",
  "pharmacies": [
    {
      "name": "강남약국",
      "address": "서울특별시 강남구 테헤란로 123",
      "phone": "02-1234-5678",
      "lat": 37.5012,
      "lon": 127.0396,
      "hours_today": "09:00~18:00",
      "is_open_now": true,
      "hours": {
        "mon": "09:00~18:00",
        "tue": "09:00~18:00",
        "wed": "09:00~18:00",
        "thu": "09:00~18:00",
        "fri": "09:00~18:00",
        "sat": "09:00~13:00",
        "sun": "휴무",
        "holiday": "휴무"
      }
    }
  ],
  "summary": "강남구 약국 5개를 찾았습니다."
}
```

> `hours_today`는 `"09:00~18:00"` 형식. `is_open_now`는 현재 KST 기준 영업 여부.

## Tips

- **영업중 우선 정렬**: 영업중(+100점) > 일/공휴일 영업(+20점) > 토요일 영업(+10점) 가중치 정렬
- **전화번호**: 모바일에서는 `tel:` 링크, 데스크톱에서는 클립보드 복사 + Toast
- **카카오맵 링크**: 위도/경도 기반 핀 링크
- **0건 시 fallback**: 공공데이터 API 0건이면 `search_web` DuckDuckGo 폴백
- **sigungu 띄어쓰기**: API는 `강남구` 형태 — "강남 구" 같이 입력해도 sanitize 처리됨
- **전국 1000건 조회**: 시군구 필터 후 클라이언트에서 동/약국명 필터링
