# Vet-Viz: Test Prompt Guide

Reference prompts for testing the `json:vet` renderer and the animal hospital search pipeline (행정안전부 동물병원 조회서비스 API).

> ⚠️ API 키 만료일: **2028-05-10** (VET_KEY — 재신청 필요)

---

## Renderer Schema

```json
{
  "query": "강남구 동물병원",
  "count": 10,
  "notice": null,
  "vets": [
    {
      "name": "강남24시동물병원",
      "address": "서울특별시 강남구 테헤란로 456",
      "phone": "02-555-0001",
      "status": "영업",
      "status_detail": "영업중",
      "license_date": "20100315"
    }
  ]
}
```

**status 값**: `영업` · `휴업` · `폐업`

> `notice`: 검색 조건 없는 요청, 광역 검색 등 안내가 필요할 때 표시되는 문자열. null이면 미표시.

## Tips

- **영업상태 뱃지**: 영업중(틸) · 휴업(앰버) · 폐업(슬레이트)
- **좌표계 제약**: API가 EPSG:5174 좌표 반환 → WGS84 변환 불가 → 병원명+주소 텍스트 기반 카카오지도 검색 링크
- **전화번호**: 모바일 `tel:` 링크 / 데스크톱 클립보드 복사 + Toast
- **인허가일자**: 병원 개원 연혁 표시 (`license_date`)
- **0건 시 동작**: 영업중 조건 → 전체 상태로 자동 재조회
- **검색 조건 없는 요청 차단**: 지역명·병원명 없이 "동물병원 찾아줘"만 입력하면 지역 입력 유도 안내
- **`펫` 키워드 주의**: `펫보험`·`펫샵` 같은 질의는 `vet_search` 미분기
