## Renderer Schema

### mode: list — 법령 목록

```json
{
  "query": "도로교통법",
  "mode": "list",
  "count": 5,
  "laws": [
    {
      "name": "도로교통법",
      "shortName": "도교법",
      "lawId": "LSW0000400",
      "mst": "123456",
      "type": "법률",
      "department": "경찰청",
      "promulgationDate": "20230101",
      "effectiveDate": "20230401",
      "revisionType": "일부개정",
      "status": "현행",
      "sourceUrl": "https://www.law.go.kr/..."
    }
  ]
}
```

### mode: body — 법령 본문 (주요 조문)

```json
{
  "query": "음주운전 기준",
  "mode": "body",
  "law": { "name": "도로교통법", "mst": "123456" },
  "articles": [
    {
      "number": "44",
      "title": "술에 취한 상태에서의 운전 금지",
      "clauses": [
        { "number": "1", "text": "누구든지 술에 취한 상태에서 자동차등...을 운전하여서는 아니 된다." },
        { "number": "2", "text": "경찰공무원은 교통의 안전과 위험방지를 위하여..." }
      ],
      "sourceUrl": "https://www.law.go.kr/..."
    }
  ]
}
```

### mode: article — 특정 조문

```json
{
  "query": "도로교통법 제44조",
  "mode": "article",
  "law": { "name": "도로교통법", "mst": "123456" },
  "articleNo": "44",
  "articles": [
    {
      "number": "44",
      "title": "술에 취한 상태에서의 운전 금지",
      "clauses": [...],
      "sourceUrl": "https://www.law.go.kr/..."
    }
  ]
}
```

## 2. 특정 조문 조회 (mode: article)

- "도로교통법 제44조 알려줘" — 술에 취한 상태에서의 운전 금지

- "개인정보 보호법 제15조 정리해줘" — 개인정보의 수집·이용
- "근로기준법 제56조 알려줘" — 연장·야간·휴일 근로 가산임금
- "상법 제398조 내용" — 이사 등과 회사 간의 거래

## 5. 첨부 문서 후속 질문 — 법령 카드를 띄우지 않는다

법령을 다룬 문서(예: 인공지능 기본법 해설 PDF)를 놓고 "계도기간은 얼마나 돼?"처럼 물으면, 라우터 LLM 이 주제만 보고 `law_*` 를 고를 수 있다.
라우터의 **Doc guard** 가 이를 `general` 로 되돌려 문서로 답하게 한다([router.ts](../../server/agent/nodes/router.ts), [DEV_261014 §9](../logs/2026/10/DEV_261014.md)).

- 조건: 이번 요청에 첨부 문서 본문이 실려 있고, 사용자가 법령을 직접 말하지 않았고(규칙 `law_search` 아님), 법령 카드가 떠 있지 않다
- 문서를 보면서 "관련 법령 찾아줘"·"제31조 원문 보여줘"처럼 직접 요청하면 법령 카드가 정상으로 나온다
- 로그: `[LangGraph] Doc guard: law_* → general`

## Tips

- **mode 분기**: 법령명 + 조번호 → `article`, 주제형 키워드 → `body`, 목록 요청 → `list`. mode 가 비면 `law_qa` 는 **`body`**(조문 근거), 카드 `law_search` 는 `list` (2026-10-18)
- **법령명·조문은 모델이 문맥으로**: 주제형 질문("영화관 소음 관련 법")은 도구 설명·해석기 프롬프트에서 공식 법령명으로 바꾸게 한다(키워드 매핑 추가 없음). 질문에 답하는 조문을 확실히 알면 `article_no`(연차휴가 → 제60조). 0건이면 해석기로 한 번 더. 조문 점수는 끝 조사 뗀 토큰·공백 제거 본문도 맞춘다
- ⚠️ **라우터 규칙은 LLM 법령 판정을 덮지 않는다**: LLM 이 `law_search`/`law_qa` 를 직접 고르면 유지, `decideLawInteraction` 규칙은 LLM 이 법령으로 안 봤을 때·카드 후속·이탈에만. law_search = 법령·조문을 보여 달라, law_qa = 법이 답하는 질문(금액·처벌·허용 여부) → [DEV_261018 §11~12](../logs/2026/10/DEV_261018.md#12-법령-카드가-질문에-답을-못함-멀티턴-eh)
- ⚠️ **근거 없는 숫자 금지**: 조회 데이터에 없는 금액·한도·비율·나이·기간은 말하지 않는다. 시행령 위임이면 "시행령 확인 필요"로 답한다(김영란법 식사비 3만 원 오답 사례, [§13](../logs/2026/10/DEV_261018.md#13-시행령에-위임된-숫자를-모델-기억으로-채움)). 시행령·별표 조회는 미지원
- **조문 accordion**: 첫 번째 조문 기본 펼침, 나머지는 접힘 상태
- **페이지네이션**: 조문 5개 초과 시 하단 `이전/다음`으로 5개씩 탐색
- **원문 링크**: 각 조문 카드에 `law.go.kr` 공식 원문 링크 — `LAW_OC`를 외부에 노출하지 않음
- **현재 미지원 범위**: 판례, 헌재결정례, 행정규칙, 고시, 신구법 비교, 별표·서식 → TODO Phase 2~4
