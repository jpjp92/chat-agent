# Paper-Viz: Test Prompt Guide

Reference prompts for testing the `json:paper` renderer and the research-paper pipeline
(**PubMed E-utilities** + **arXiv API**). 카드는 하나이고 `source` 로 갈린다.

> `NCBI_KEY` 는 문법상 **선택**이지만 배포 환경에서는 사실상 필수다 — 무키는 3 req/s 라
> 병렬 호출에서 429 가 나고, Vercel 은 동시 인스턴스가 egress IP 를 공유한다.
> 로컬 `.env` · Vercel 대시보드 양쪽 등록 완료(2026-08-30).

## Renderer Schema

```json
{
  "query": "probiotics common cold prevention",
  "total": 54,
  "papers": [
    {
      "pmid": "23372900",
      "title": "The effect of probiotics on prevention of common cold: a meta-analysis…",
      "journal": "Korean journal of family medicine",
      "year": "2013",
      "authors": ["Kang EJ", "Kim SY", "Hwang IH"],
      "evidence": null,
      "retracted": false,
      "doi": "10.4082/kjfm.2013.34.1.2",
      "url": "https://pubmed.ncbi.nlm.nih.gov/23372900/",
      "summary": "10개 연구 2,894명 대상. 상대위험도 0.92로 예방 효과는 미미했다.",
      "summaryKind": "conclusion"
    }
  ],
  "retracted":  [ /* 철회된 논문 — 번호 없음, 빨강 칸 */ ],
  "noAbstract": [ /* PubMed 에 초록이 없는 논문 — 번호 없음, 회색 칸 */ ]
}
```

**`summaryKind`** — 요약이 무엇인지 밝힌다. 이게 없으면 곁가지 문단이 결론인 척 읽힌다.

| 값 | 뜻 | 카드 표시 |
|---|---|---|
| `conclusion` | `<AbstractText Label="CONCLUSIONS">` 원문 | 라벨 없음 |
| `excerpt` | 라벨 없는 통짜 초록에서 **위치로 집은** 대목 | `초록 발췌` 회색 칩 |
| `none` | PubMed 에 초록이 없다(실측 8%) | `papers` 에 없음 — `noAbstract` 칸으로 |

🔴 **`papers` 는 인용 가능한 논문만 담는다.** 인용 마커 `[n]` 이 이 배열의 순번이므로,
철회 논문과 초록 없는 논문을 빼면 **모델이 번호로 가리킬 수가 없다**. 프롬프트로 막는 건
3회 중 2회(철회) · 3회 중 3회(초록 없음) 실패했다 — 자세한 측정은 DEV 로그 §6.10.

**`evidence` 값**: `"meta-analysis"` · `"rct"` · `"review"` · `null` (PubMed 전용)

| evidence | 배지 (ko) | PubMed pubtype |
|---|---|---|
| `meta-analysis` | 종합분석 | `Meta-Analysis` · `Systematic Review` |
| `rct` | 임상시험 | `Randomized Controlled Trial` |
| `review` | 논문 리뷰 | `Review` |
| `null` | **표시 없음** | `Journal Article` 뿐 |

## 🔴 네 가지 설계 계약

근거 카드라 **조용히 틀리면 해로운** 지점이 넷 있다. 전부 `tests/test-paper-card.mts` 가 지킨다.

### 1. `evidence: null` 을 추정으로 채우지 않는다

`pubtype` 은 NLM 큐레이터가 **나중에** 붙인다. 그래서 제목에 `a meta-analysis` 라고 적힌
논문(PMID 23372900)이 `['Journal Article']` 로만 오는 일이 흔하다.

실측(의학 질의 6종 240건): **pubtype 확정 64% · 미분류 35%.** 질의별 편차가 크다 —
`metformin` 은 88% 분류돼 있고 `hypertension korean` 은 25% 뿐이다. **국내 논문일수록 미분류가 많다.**

제목으로 보조 판정하는 안을 넣어봤지만 240건 중 **3건(1%)** 밖에 못 건져 폐기했다.
미분류는 "등급이 낮다"가 아니라 "아직 분류가 안 됐다"이므로, 최하위처럼 보이는 칩을 달면
사실과 반대되는 신호가 된다. 그래서 배지를 **아예 그리지 않는다.**

같은 이유로 다른 카드에 있는 **좌측 색 스트라이프를 쓰지 않는다** — 띠로 서열을 그리면
배지 없는 카드가 자동으로 꼴찌로 읽힌다. `json:hospital` 은 모든 병원이 종별을 갖고 있어
성립하던 장치다.

### 2. 이해상충(COI) 플래그를 만들지 않는다

`<CoiStatement>` 는 태그 존재만으로 판정할 수 없다 — 대부분이 "이해상충 **없음**" 선언이다.
본문을 규칙으로 분류해보니 실제 41건에서 **양방향 오분류가 20% 넘게** 났다:

- `"has received research grant support and consulting"` → 없음으로 오분류
- `"conducted in the absence of any commercial or financial relationships"` → 있음으로 오분류

저자의 재정적 편향을 표시하는 플래그가 5건 중 1건 틀리면 정직한 연구자를 부당하게 깎거나
후원 연구에 잘못된 안심을 준다. 필요하면 **모델이 본문을 읽고 산문으로 언급**하는 게 맞다.

### 3-0. arXiv 검색어는 AND 로 조립한다 (`buildArxivSearchQuery`)

`search_query=all:<질의>` 는 공백을 **OR** 로 읽는다. `all:transformer attention optimization`
은 576,986건을 반환하고 상위 5건 중 2건이 "optimization" 하나만 걸린 무관 논문이었다
(실측 2026-08-31, 화면에서 발견). 단어마다 `all:` 을 붙여 ` AND ` 로 이으면 2,776건에
상위 5건 전부 관련이다.

- 기능어(`is`·`the`·`for`·`all`·`using`…)는 뺀다 — arXiv 가 색인하지 않아 AND 가 0건이 된다
- `cat:`·`ti:` 같은 필드 접두사나 `AND`/`OR` 가 이미 있으면 손대지 않는다 (`all:all:` 방지)
- 🔴 **0건을 OR 로 넓히지 않는다.** `sourdough fermentation microbiome kinetics` 는 AND 0건이
  정답이다(arXiv 에 없는 분야). 넓히면 "kinetics" 만 걸린 논문이 근거가 되고, 무의미어는
  35,416건의 토픽모델링 논문을 물어 온다. 아래 §3 의 "빈손으로 실패하지 않는다" 가 이 실패다

⚖️ **정정(2026-09-03): *"`all:"구문 전체"` 는 색인이 없어 늘 0건"* 은 틀렸다.** 근거가
`all:"transformer attention optimization"` **하나**였는데 그건 애초에 진짜 구절이 아니다.
논문 제목은 걸린다 — `all:"Attention Is All You Need"` 45건, 원 논문 2위. 아래 §3-2 참고.

### 3-1. 검색어에 범용어를 덧붙이지 않는다 (도구 설명)

AND 로 묶이므로 **사용자가 말하지 않은 단어가 교집합의 순위를 자기 쪽으로 끌어당긴다.**
실측(2026-09-03): `트랜스포머 논문 찾아줘` 에 모델이 `transformer neural network` 를 보내
상위 5건 중 관련 **1건**(원 논문 없음, 베이즈 필터·음향 인식). `transformer` 만 보내면 5/5.

🔴 **코드로 막으면 안 된다.** 범용어를 AND 에서 빼는 수정을 넣었더니 `graph neural network`
가 5/5 → **0/5**(그래프 이론), `convolutional neural network` 가 **1/5**(부호이론)로 무너졌다.
`neural network` 는 어떤 질의엔 군더더기고 어떤 질의엔 개념의 절반이다 — **가르는 건 문맥이고
문맥은 모델만 안다.** 그래서 도구 설명에서 막는다.

🔴 **문안은 `ARXIV_QUERY_DESCRIPTION` 상수 하나다.** 처음엔 `arxiv-tool.ts` 의 zod 스키마만
고쳤는데, OpenAI 경로는 그 스키마를 안 쓰고 `local-tool-registry.ts` 에 **자기 사본**을 갖고
있어 안 고쳐졌다. gpt-5.6-luna 가 `Attention Is All You Need Transformer architecture
self-attention` 으로 조회해 원 논문 없는 카드를 냈다. **논문 도구 문안을 만지면 두 파일이
아니라 상수 하나인지 먼저 확인한다.**

### 3-2. 제목 질의는 구절을 먼저 친다 (`buildArxivQueryPlan`)

제목은 키워드 묶음이 아니다. `Attention Is All You Need` 는 다섯 단어 중 `is`·`all`·`you` 가
불용어라 `all:Attention AND all:Need`(7,982건)로 줄고 **원 논문이 상위 5건에 못 든다.**

가르는 신호는 **버려지는 불용어의 존재**다 — 평범한 검색어(`graph neural network`,
`probiotics depression`)에는 하나도 없고 제목·구절에는 있다. 불용어가 섞였을 때만
`ti:"<원문>"` 을 먼저 치고, 0건이면 기존 AND 조립으로 내려온다.

🔴 **`all:` 이 아니라 `ti:` 다.** `all:"Attention Is All You Need"` 는 원 논문이 **2위**이고
1위는 2026년 `Tool Attention Is All You Need` 다. 모델이 `limit:1` 로 부르면 **카드에 그 논문만
남고 산문이 그걸 답으로 설명한다**(실측 2026-09-03). `ti:` 는 1위다 — 제목을 물었으면 제목 필드를 본다.

⚖️ 가운데에 `all:"…"` 를 끼운 3단 계획은 뺐다 — 구절 6종에서 **`ti:` 가 0이면 `all:"…"` 도
예외 없이 0**이라 단독으로 건진 경우가 없는데 최악 지연만 두 배가 된다.

- ⚠️ 한 번에 합치는 `all:"…" OR (AND 조립)` 은 **안 된다** — 관련도 정렬이 구절 일치를
  우대하지 않아 원 논문이 여전히 상위 밖이다(실측). 그래서 순차 폴백이다
- 3단어 미만은 구절로 보지 않는다(`based on` 같은 조각이 걸린다)
- 폴백 비용 **~3초**, 거의 전부 arXiv 가 요구하는 `MIN_GAP_MS` 대기다. 한국어 질의는 번역에서
  기능어가 떨어져(`위한` → 사라짐) 대개 계획이 1개라 **추가 호출이 없다**

관련도는 **하니스로 못 잡는다**(산문↔카드만 본다). `tests/manual/live-arxiv-query.mts` 가
실제 arXiv 로 상위 5건을 가져와 잰다 — 조립을 만졌으면 이걸 돌리기 전에는 판단할 수 없다.
⚠️ **숫자만 보지 말고 제목을 읽을 것.** 관련도 정규식이 느슨해(`/graph/i`) 회귀를 5/5 로
보이게 만든 적이 있다.

### 3. arXiv 는 프리프린트다 — 근거 등급을 재사용하지 않는다

`meta-analysis`·`rct`·`review` 는 NLM 큐레이터가 연구 **설계**를 분류한 값이고 arXiv 에는
그런 분류가 없다. arXiv 에서 확실히 말할 수 있는 건 `journal_ref`/`doi` 존재 여부 하나뿐이라
**게재됨 / 프리프린트**만 표시한다.

| source | 배지 | 근거 |
|---|---|---|
| `pubmed` | 종합분석 · 임상시험 · 논문 리뷰 · (없음) | `pubtype` |
| `arxiv` | 게재됨(초록색) · 프리프린트(회색) + 분류칩(`cs.LG`) | `journal_ref` 또는 `doi` 존재 |

프리프린트를 **회색 중립색**으로 두는 건 "등급이 낮다"가 아니라 "심사 전"이라는 뜻이다.
그 사실을 숨기면 심사 안 된 글이 심사된 것처럼 읽힌다 — 하단 문구도 4개 언어 모두 이걸 밝히고,
프롬프트는 결과·벤치마크·안전 주장을 다룰 때 산문에서 한 번 짚게 한다.

### 4. 두 DB 모두 어떤 질의에도 빈손으로 실패하지 않는다

트리거 조건은 "의학 주제인가" 가 아니라 **"논문을 요청했는가"** 다. 분야는 그 다음에 갈린다.
어느 쪽이든 잘못 보내면 **0건이 아니라 그럴듯한 엉뚱한 논문**이 근거랍시고 나간다:

| 질의 | PubMed 가 주는 것 |
|---|---|
| 머신러닝 트랜스포머 논문 | 단일세포 오믹스·의료 AI 응용 (원논문 아님) — **차단 대상** |
| 최저임금 인상 효과 | 최저임금이 흡연·아동 행동에 미친 영향 — 경계 사례 |
| 기후변화·미세먼지 | 기후-건강, 대기오염 노출 연구 — **실체 있는 공중보건 문헌이라 허용** |
| 한국어 통사론 → arXiv | `astro-ph` **Korean VLBI Network**(전파망원경) — **차단 대상** |
| 인상주의 회화 → arXiv | `cs.CV` *Collaborative Neural Painting* — **차단 대상** |

전부 진짜 논문이다. 그래서 문제는 "가짜냐" 가 아니라 **"사용자가 기대한 관점이냐"** 이고,
답은 주제마다 다르다. 3중으로 다룬다:

1. **`topic_field` + `paper_source`** — 라우터 JSON 에 두 칸을 더 받아 어느 DB 가 답할 수
   있는지 **3분기**로 가른다(`pubmed` / `arxiv` / `none`). `none` 이면 `general` 로 강등한다. 추가 LLM 호출은 없다. 판정은 **2단계**다:
   ① `topic_field` 로 주제를 학문 분야로 먼저 명명하고("art history", "monetary policy")
   ② 그 분야가 **무엇을 연구하는가**로 DB 를 고른다:
   **살아있는 몸**(생물·구조·기능·질병·돌봄) → `pubmed` ·
   **형식·물리·계산 체계**(수학·물리·알고리즘·기계·계량경제) → `arxiv` ·
   **사람의 기록**(텍스트·작품·사건·제도·법) → `none`.
   같은 단어의 양쪽은 대상이 가른다 — 음악치료(pubmed)/음악학(none),
   계산언어학(arxiv)/한국어 통사론(none).

   🔴 **분야를 열거하면 안 된다.** 처음엔 "심리학은 true, 문학은 false" 식으로 적었는데,
   그러면 적어둔 분야만 맞고 고고학·언어학·건축학처럼 안 적은 분야는 그대로 샌다 —
   `isNonBiomedicalPaperTopic()` 블록리스트가 21분야 중 차단 대상 10종을 전부 놓친 것과
   같은 구조다(비의생명 분야의 공간은 무한하다). 규칙으로 바꾼 뒤 **프롬프트에 이름이 없는
   14분야에서 42/42** 정확했다 — `live-paper-routing.mts --unseen` 이 이 경계를 지킨다.
   키워드 가드와 `intentRules.ts` 규칙 폴백은 라우터 LLM 이 429 로 죽었을 때의 2차 방어다
   (⚠️ 키워드 가드는 `paper_search` 에만 건다 — 그게 잡는 CS·공학 어휘가 arXiv 에서는 정답이다).

   🔴 **`arxiv_search` 는 모델이 고르는 의도가 아니다.** 프롬프트 의도 목록에 넣었다가 뺐다 —
   모델이 "논문 요청인가"와 "어느 분야인가"를 두 번 판단하면 두 판단이 어긋난다.
   의도는 `paper_search` 하나로 받고 `paper_source` 에서 코드가 파생시킨다.
2. **프롬프트 백스톱** — 주제가 건강보다 넓으면(기후·노동환경) 카드를 **보여주되 "보건 관점
   연구" 임을 한 마디로 밝히게** 하고, PubMed 가 아예 다루지 않는 분야면 카드를 내지 않게 한다.
3. **카드 자체** — 하단 문구가 4개 언어 모두 "PubMed(의생명 분야 문헌)" 라고 출처 범위를
   밝힌다. 라우팅이 새더라도 사용자는 어디서 온 근거인지 항상 본다.

## 🔴 인용할 수 없는 논문은 번호 목록에서 뺀다 (화면에서는 빼지 않는다)

두 종류다.

| | 왜 못 쓰나 | 카드 |
|---|---|---|
| **철회** (`pubtype` 에 `Retracted Publication`) | 저널이 철회했다 — 결과가 근거가 아니다 | 빨강 칸 `철회되어 제외된 논문` · 제목에 취소선 |
| **초록 없음** (실측 8%) | PubMed 에 초록이 없어 내용을 알 수 없다 | 회색 칸 `초록이 없어 요약하지 못한 논문` |

⚖️ **두 칸을 합치지 않는다.** 철회는 "믿지 마라", 초록 없음은 "우리가 요약을 못 한다" 다.
한 상자에 담으면 멀쩡한 논문에 철회의 색이 묻는다.

⚠️ `Retraction of Publication` 은 **뜻이 정반대**다 — 남의 철회를 알리는 공고문이다.
`Expression of Concern` 도 철회가 아니다. 둘 중 하나라도 철회로 잡으면 정상 문헌을 깎는다.

목록에서 빠지는 만큼 근거가 얇아지므로 `retmax` 를 `limit + 3` 으로 받고 필터 뒤에 자른다.

## 🔴 카드는 스트리밍과 별개로 보내야 한다

Gemini 는 산문을 토큰 단위로 흘리고, 카드는 그 뒤 최종 메시지에 붙는다. `stream-dispatch.ts` 가
"스트리밍이 없을 때만 최종 메시지를 보낸다" 였던 탓에 **Gemini 에서만 카드가 통째로 사라졌다**
(OpenAI 는 이 경로로 스트리밍하지 않아 우연히 멀쩡했다 — 모델 품질 차이로 오인하기 쉽다).

전송 판정은 `pendingCardBlocks()` 하나에 있고 `stream-dispatch.ts` 와 `live-paper-card.mts` 가
**같은 함수**를 쓴다. 하니스는 최종 메시지가 아니라 **실제로 보내는 것**을 본다.

같은 이유로 논문 턴에서는 인용 번호 `[1]`·`[2]` 를 지우지 않는다 — 그 번호는 도구가 준 논문
순번이고 산문과 카드를 잇는 유일한 끈이다. 게이트는 `stripCitations` 호출부에 건다
(`stripFabricated` 의 한 줄 형태는 `test-gemini-citations` 가 정규식을 추출해 쓰므로 건드리지 않는다).

## 산문은 3문단이다 — 분량이 아니라 구조를 준다

`(3-5 sentences)` 처럼 **문장 수만** 주면 모델은 한 덩어리로 쓴다. 읽히지 않는다.
`INTENT_FOCUS_HINTS` 는 대신 모양을 준다:

| 문단 | 내용 |
|---|---|
| 1 | 결론 한 문장 — 여기서 멈춰도 답이 된다 |
| 2 | 연구가 보인 것과 한계 (2~3문장) · 인용 마커 `[1][2]` |
| 3 | 마무리 한 문장 — 상담·확인할 것 |

- **빈 줄이 문단 구분자다.** 홑개행은 ReactMarkdown 이 문단으로 끊지 않아 화면에선 한 덩어리다.
- **헤딩·불릿 금지.** 불릿으로 쓰면 카드와 내용이 겹쳐 같은 걸 두 번 읽게 된다.
- 총 3~5문장 상한은 유지. 문단을 나누라는 것이지 길게 쓰라는 게 아니다.

CSS 는 이미 맞다 — `ChatMessage.tsx` 의 `p` 렌더러가 `mb-4 leading-relaxed` 를 준다.
간격이 안 벌어지면 CSS 가 아니라 **모델이 빈 줄을 안 넣은 것**이다.

---

## 인용 번호는 카드 순번이다 — 각주 번호가 아니다

`[n]` = **카드에서 위에서 n번째 논문**. 모델이 자기가 언급한 순서로 다시 매기면
(4번을 먼저 쓰고 `[1]`) 산문은 참인데 귀속이 틀린다 — 사용자가 카드 1번을 열었을 때만 드러난다.

- **건너뛰기가 정상이다.** `[5] … [4] … [2]` 가 옳은 답이고 1·3번은 언급 안 해도 된다.
- **1위가 정답이 아니다.** PubMed·arXiv 자체 관련도라 무관한 논문이 1위로 온다
  (프로바이오틱스 질의에 비타민C 종설이 1위로 온 실측 사례). 그러면 `[1]` 을 비워둔다.

하니스(`live-paper-card.mts`)는 **변별 질문**으로 본다 — 논문 목록 전체를 주고 "이 문장은
몇 번을 말하는가" 를 묻고, 모델이 쓴 번호가 그 답에 들어있는지 대조한다.
"n번이 이 문장을 뒷받침하는가" 로 물으면 안 된다: 묶음 인용(`[3][4]`)에서 오탐이 나고,
그걸 완화하면 엉뚱한 논문도 통과한다(둘 다 실측).

## 로컬 확인 체크리스트

```bash
npm run dev        # 또는 npx vercel dev
```

각 항목은 **무엇을 보는지**가 다르다. 순서대로 가면 카드의 계약을 전부 훑는다.

### A. PubMed 로 가야 한다 (`source: pubmed`)

| 질의 | 확인할 것 |
|---|---|
| 프로바이오틱스가 감기 예방에 효과 있는지 논문 찾아줘 | 기본 동작. 배지 혼재 + **미분류 카드가 배지 없이** 렌더 |
| 메트포르민 2형 당뇨 메타분석 | **종합분석**(보라) 배지 |
| 인플루엔자 백신 효과 임상시험 | **임상시험**(파랑) 배지 |
| 한국인 고혈압 치료 관련 논문 | 국내 주제 — 미분류 비율이 특히 높다 |
| 음악치료 불안 완화 연구 있어? | `논문` 이라는 단어가 없어도 잡히는가 (한 번 회귀했던 지점) |
| 반려견 슬개골 탈구 연구 논문 | 수의학도 PubMed 다 |
| 기후변화가 건강에 미치는 영향 연구 | 카드는 뜨되 산문이 **"보건 관점 연구"** 임을 밝히는가 |

### B. arXiv 로 가야 한다 (`source: arxiv`)

| 질의 | 확인할 것 |
|---|---|
| 강화학습 보상 설계 관련 논문 찾아줘 | `cs.AI`/`cs.LG` 분류칩 · **프리프린트**(회색) 배지 |
| 트랜스포머 어텐션 최적화 논문 알려줘 | 대부분 프리프린트 — 산문이 동료심사 전임을 밝히는가 |
| 인플레이션과 통화정책 논문 | `econ.EM` — 경제도 arXiv 다 |
| 이족보행 로봇 제어 논문 | `cs.RO` · **게재됨**(초록) 배지가 섞여 나온다 |
| 반도체 공정 관련 논문 찾아줘 | `cond-mat` |
| 트랜스포머 논문 찾아줘 | 🔴 **검색어가 `transformer` 인가.** `transformer neural network` 면 §3-1 회귀 |
| Attention Is All You Need 논문 찾아줘 | 🔴 **카드에 1706.03762 이 있는가.** 없으면 §3-2 구절 폴백이 죽은 것 |
| 그래프 뉴럴 네트워크 논문 찾아줘 | 복합 개념이 통째로 가는가 — 쪼개지면 그래프 **이론** 논문이 온다 |
| 의료 영상 분할을 위한 딥러닝 논문 | 검색어에 `for`·`위한` 이 안 붙는가. 카드 5건이 전부 주제인가 |

하단 문구가 **"arXiv 는 프리프린트 저장소라…"** 로 바뀌는지 꼭 본다(PubMed 문구가 남아 있으면 버그).

🔴 **검색어를 눈으로 확인하려면 서버 로그를 본다** — 화면에는 카드 헤더의 `query` 만 보인다.
OpenAI 경로는 `[OpenAI] local tool "search_arxiv" ← {"query":…}` 한 줄에 인자가 찍힌다.

### C. 카드가 뜨면 안 된다

| 질의 | 왜 |
|---|---|
| 셰익스피어 비극 연구 논문 찾아줘 | 문학 — PubMed 는 "Ophelia syndrome" 을 준다 |
| 인상주의 회화 미술사 논문 | 예술사 — PubMed 는 **"인상주의 회화 속 여성의 BMI"** 를 준다 |
| 한국어 통사론 연구 알려줘 | 언어학 — arXiv 는 `astro-ph` **Korean VLBI Network** 를 준다 |
| 조선시대 신분제 연구 논문 | 역사학 |
| 복식부기 회계처리 연구 자료 | 회계학 |
| zzzqqq disease 논문 찾아줘 | 0건 — 빈 카드를 띄우면 안 된다 (실측 0건 확인된 질의) |

C 는 **"카드가 없다"로 끝나면 안 된다.** 검색 그라운딩으로 넘어가 실제 답을 주는지까지 본다
(셰익스피어는 『한신논문집』·『성곡논총』 같은 진짜 국내 논문이 각주와 함께 나온다).

### D. 기존 의도를 잠식하지 않는다 (회귀)

| 질의 | 가야 할 곳 |
|---|---|
| 고혈압에 좋은 음식 알려줘 | `medical_qa` — 논문 요청이 아니다 |
| 감기 걸렸는데 어떻게 해? | `medical_qa` |
| 타이레놀 성분 알려줘 | `drug_info` |
| 강남구 내과 찾아줘 | `hospital_search` |
| 헌법 개정 관련 법령 알려줘 | `law_search` — 법령 카드가 더 나은 답이다 |
| 논문 써줘 / 논문 형식으로 정리해줘 | **작성 요청**이지 조회가 아니다 → 카드 없음 |

### E. 모델을 바꿔가며 (생성 경로가 둘이다)

Gemini 는 LangChain, OpenAI 는 Responses API 로 **완전히 다른 경로**를 탄다. A·B 에서 하나씩 골라
`gemini-3.7-flash` · `gpt-5.4-mini` 양쪽에서 돌려본다. 볼 것은 셋:

1. 카드 앞에 **산문이 있는가** (카드만 나오면 근거의 해석이 빠진다)
2. 산문의 PMID/arXiv ID·DOI 가 카드와 **같은가** (모델이 식별자를 고치면 안 된다)
3. 모델이 **자기가 쓴 카드**를 내지 않았는가 (`pinCardToProse` 가 도구 출력으로 고정한다)

🔴 **도구 스키마·설명을 만졌으면 두 공급자 모두에서 돌린다.** 두 경로는 파라미터 정의를
공유하지 않았던 적이 있고(§3-1), 한쪽만 고친 채 초록으로 남았다. 2026-09-03 의 회귀는
Gemini 에서는 안 보이고 `gpt-5.6-luna` 에서만 보였다.

⚠️ **답이 정확하다고 카드가 나온 게 아니다.** 카드 없이 웹 grounding 으로 답해도 내용은
맞을 수 있다 — 근거 칩이 `json:paper` 카드인지 출처 칩인지로 갈린다. 실제로 이걸로 한 번
속았다. 확실한 판별점은 서버 로그의 도구 호출 줄이다.

### F. 멀티턴

카드가 뜬 뒤 **"세 번째 논문 좀 더 설명해줘"** → 카드를 다시 그리지 않고 산문으로 답해야 한다.
이어서 **"그럼 비타민D 는?"** → 새 카드가 떠야 한다.

### G. 인용 정렬 — 번호를 다시 매기고 싶게 만드는 질의

`[CITATION NUMBERING]` 을 넣은 뒤의 라운드. **산문의 번호를 카드에서 직접 세어 대조한다.**

| 질의 | 노리는 것 |
|---|---|
| 프로바이오틱스가 감기 예방에 효과 있는지 논문 찾아줘 | 관련도 1위가 **무관한 논문**(비타민C 종설)으로 오는 실측 케이스. `[1]` 을 비워두는가 |
| 메트포르민 심혈관 사망률 논문 | 뒤쪽 논문부터 인용하게 되는 주제 — `[4]`·`[5]` 로 시작하는가, `[1]`·`[2]` 로 되매기는가 |
| 겸상적혈구빈혈 유전자치료 논문 | 후보가 적다. 1~2건이면 번호 선택지가 없어 정렬 오류가 안 드러난다 — **대조군** |
| 트랜스포머 어텐션 최적화 논문 알려줘 | arXiv 경로도 같은 규칙을 받는가 |

🔴 볼 것: 산문의 `[n]` 을 카드에서 **위에서 n번째** 항목과 하나씩 대조한다. 내용이 맞아도
번호가 어긋나면 결함이다 — 실측된 실패는 전부 "문장은 참인데 번호만 틀림" 이었다.

### H. 문단 구조 — 3문단이 어색해지는 자리

`3문단` 은 근거가 있을 때의 모양이다. **근거가 없거나 답이 짧을 때** 어떻게 되는지 아직 안 봤다.

| 질의 | 확인할 것 |
|---|---|
| zzzqqq disease 논문 찾아줘 | 0건이라 카드가 없다. "찾지 못했다" 한 줄이면 되는데 **3문단을 채우려 말을 지어내지 않는가** |
| 셰익스피어 비극 연구 논문 찾아줘 | 카드 없이 검색 그라운딩으로 답할 때 3문단 규칙이 따라붙어 어색하지 않은가 |
| 이족보행 로봇 제어 논문 | arXiv — **프리프린트 고지가 2문단에 들어가는가**(3문단으로 밀리면 안 된다) |
| Do probiotics prevent the common cold? | 영어 질의에서도 3문단·인용 번호가 유지되는가 |

가리킬 곳이 없는 마커가 된다. 프롬프트로는 2/2 실패해서 코드로 막았다.

메타분석(40969681)을 정당하게 돌려준다. 지킬 것은 겹침이 아니라 번호가 새 카드 기준인가다.

### 후속 판정 규칙 (`decidePaperCardFollowup`)

```
새로 찾아와 신호(`다른 논문`·`더 찾아`·`재검색`)  → new     (우선)
카드 항목 지목(`세 번째`·`2번`·`[3]`·`그 논문`)   → discuss (조회 동사가 없을 때만)
재구성(`표로`·`정리해`·`비교해`·`쉽게`)            → discuss (조회 동사가 없을 때만)
그 외                                              → new
```

⚖️ **조회 동사가 가른다** — `3번 염색체 관련 논문 찾아줘` 는 숫자가 지목이 아니라 주제어다.
⚠️ 논문 의도일 때만 본다 — 논문 카드가 떠 있어도 `오늘 서울 날씨?` 는 날씨로 가야 한다.
`discuss` 턴은 `needsSearch=false` 다. 검색을 켜면 카드에 없는 논문을 끌어와 번호가 어긋난다.

### 🔴 마커는 이번 턴 카드만 가리킨다 — 스트림에 걸어야 한다

`[n]` 이 `papers` 범위 밖이면 코드가 걷어낸다(`dropMarkersOutsideRange`). 문장은 남기고
마커만 지운다. `[3](url)`(grounding 링크)은 건드리지 않는다.

⚠️ **`pinCardToProse` 에만 걸면 절반만 고쳐진다.** 그건 최종 메시지에 걸리는데, Gemini 는
산문을 토큰으로 흘려 **사용자에게 먼저 보낸다**. 도구 종료(#19)가 본문 첫 토큰(#24)보다
먼저 오므로, `stream-dispatch.ts` 가 `on_tool_end` 에서 건수를 잡아 스트림에도 건다.
라이브 하니스도 **같은 함수를 import** 한다 — 복제하면 규칙이 갈라져도 초록으로 남는다.

| 질의 | 왜 |
|---|---|
| 카드 렌더 스냅샷 | `render-paper-card.mts` 는 HTML 문자열만 본다. 실제 브라우저에서 두 상자의 간격·다크모드는 아직 눈으로 안 봤다 |
| 8건 초과(`limit` 상한) 질의 | `retmax = limit + 3` 이 `MAX_RESULTS` 8 에서 잘린다 — 제외가 많은 질의에서 목록이 얼마나 얇아지는지 |
| `Attention Is All You Need` 가 `all:transformer` 상위에 없다 | arXiv `sortBy=relevance` 는 인용수·영향력을 안 본다. **"5/5 관련"과 "사람이 원한 답"은 다르다** — "대표 논문"류는 카드보다 웹 grounding 이 나을 수 있다 |
| ~~링크형 `[N](url)` 우회~~ → **수정됨(2026-09-03)** | `repairPaperMarkerLinks` 가 URL 로 번호를 교정한다. ⚖️ **처음 진단이 틀렸다** — 실제 사례의 `[1]` 은 범위 **안**이라 `dropMarkersOutsideRange` 로는 원리적으로 못 잡았다. 판정 근거는 번호가 아니라 URL 이다 |
| 모델이 `limit: 1` 로 부르면 카드가 1건이 된다 | `ti:` 로 제목 질의는 1위가 원 논문이 됐지만, 일반 질의에서 1건짜리 카드는 여전히 나갈 수 있다. 하한을 둘지는 미정 |
| **동음이의 학술어** | `graph`(GNN / 그래프 이론) · `diffusion`(생성모델 / 확산방정식). `확산모델 논문` 카드 5건 중 1건이 `math.AP` 개체군 모델이었고 산문이 성실히 요약했다. 블로클리스트로는 못 막는다(위 §3 참고) — 라우터 `topic_field` 로 좁히는 방향은 측정 필요 |
| 산문의 "모두 프리프린트" 과잉 단정 | `journal_ref` 부재를 산문이 *"정식 출판되지 않았다"* 는 **사실 주장**으로 옮긴다. 배지는 정확한데 문장이 샌다(Music Transformer 는 ICLR 2019 게재작) |
| 카드 문구 `N건 중 관련도 상위 M건` | `total` 과 `papers.length` 사이에 **필터가 있는 것처럼** 읽힌다. arXiv 쪽엔 그 필터가 없고 M 은 모델이 넘긴 `limit` 이다 — 실제로 이 문구 때문에 없는 필터를 찾으러 갔다 |
