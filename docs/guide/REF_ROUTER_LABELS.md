# REF_ROUTER_LABELS — 라우터 의도 정답 기준

> 라우터 시험 세트·골든셋의 기대값을 정하는 기준. 사람과 LLM judge(`tests/manual/probe-router-judge.mts`)가 같은 문서를 본다.
> 라우터 프롬프트(`server/agent/nodes/router.ts`)를 그대로 옮긴 것이 아니라 **사용자가 받아야 할 결과** 기준이다.
> 결정 경위: [PLAN_DECISION_ROUTER_261019 §16·§18](../plans/PLAN_DECISION_ROUTER_261019.md). 최종 갱신 2026-10-23.

## 원칙

1. **사용자가 무엇을 받고 싶은가**로 정한다. 문장에 나온 분야 단어(약국·법·날씨·영화·논문·별)는 근거가 아니다.
2. 조회 의도(약국·병원·동물병원·법령·영화·날씨·논문)는 그것을 **찾아 달라 / 보여 달라 / 그것으로 답해 달라**일 때만.
3. 렌더러(biology·chemistry·physics·astronomy·data_viz)는 **그림·시뮬레이션·차트를 보고 싶을 때만**. 같은 주제의 설명·이유 질문은 general.
4. 어느 쪽이어도 사용자가 틀린 답을 받지 않는 문장은 `alt` 로 둘 다 인정한다. 억지로 하나를 고르지 않는다.

## 의도별 기준

| 의도 | 정답일 때 | 아닐 때(→ 다른 의도) |
|---|---|---|
| `drug_info` | 특정 약(제품명·성분명)의 효능·부작용·용량·복용 가능 여부·상호작용 | 약 이름 없는 후속("그럼 술은?")은 문맥 따라 general/medical_qa · 약사 진로·약국 창업 → general |
| `medical_qa` | **사람의** 건강 걱정(증상·질병·부상·치료) · 질병·증상의 기전 · **건강 가이드라인 권장량**(영양·카페인·수분) | 동물의 건강·돌봄(질병·예방접종·사료) → general(병원 찾기면 vet_search) · 건강한 몸·생물의 정상 작동 설명(세포·장기·유전자·감각) → general(`alt: biology`) · 의료 직업·입시·병원비 결제 → general · 육아·생활 일정(낮잠·수유 횟수) → general |
| `pharmacy_search` · `hospital_search` · `vet_search` | 장소를 찾아 달라(지역·영업시간·진료과) | 반려동물 일상 돌봄·예방접종 시기 → general · 직업·개업 → general |
| `law_search` | 법령·조문 **원문/목록을 보여 달라** | 법을 읽는 법·법학 공부 → general |
| `law_qa` | 법이 답하는 질문 — 권리·의무, 허용 여부, 처벌, 분쟁 대처 | **행정·금융 절차**(세금 신고·공제, 보험 청구·보장, 지원금·금융상품 신청, 기한·서류) → general (R5) · 변호사 비용·법조 진로 → general |
| `movie_search` | 극장 상영시간표·지금 상영작 | 줄거리·리뷰·관객수·OTT 추천 → general |
| `weather` | 장소의 현재 날씨·단기 예보 | 계절·현상(장마·태풍·미세먼지) → general+검색 · 날씨 단어가 든 노래·관용구 → general |
| `paper_search` | 논문·연구를 찾아 달라 — 생체·의학 분야(pubmed) | 논문 쓰는 법·인용 형식 → general · 특정 회사·인물이 **무엇을 하는지**("뉴럴링크 BCI 최근 연구 동향") → general(그들의 논문 요청은 유지) · 인문·역사·법 분야 논문 → general(두 DB 밖) |
| `arxiv_search` | 논문을 찾아 달라 — 수학·물리·컴퓨팅·공학 분야 | 공부 순서·강의 추천 → general |
| `biology` · `chemistry` · `physics` · `astronomy` · `data_viz` | 구조·분자·시뮬레이션·하늘 지도·차트를 **보여 달라**. astronomy 는 **오늘 밤 하늘 어디에 보이는지**(별자리·행성 위치)도 포함 | 같은 주제의 설명·이유 → general. 분자 수준 현상의 이유(소금이 녹는 이유)는 `alt: chemistry` |
| `general` | 나머지 전부 — 코드·글쓰기·추천·상식·잡담 | |

## 결정 기록

- **R4 (10-23):** 특정 약의 복용 가능 여부·상호작용은 drug_info. 이어지는 약 이름 없는 후속은 대화 기록으로 general/medical_qa 가 답한다.
- **R5 (10-23):** 행정·금융 절차는 general, 권리·허용·처벌·분쟁은 law_qa.
- **권장량 (10-23):** 건강 가이드라인 권장량(영양·카페인·수분·수면·운동)은 medical_qa 가 원칙이고 `alt: general` 도 인정한다 — 어느 경로로 가도 권장 수치 답은 정상이다.
- **동물 건강 (10-23):** medical_qa 는 사람만. 동물의 질병·예방접종은 general — 골든셋 첫 측정에서 Gemini 가 "강아지 예방접종"을 medical_qa 로 보냈다.
- **생물 설명 (10-23):** 건강 걱정 없는 정상 생리 설명(세포 분열·적혈구·시각)은 general. 질병·증상 기전은 medical_qa.
- **날씨 후속 (10-23):** 같은 도시 다른 날짜는 refine. 10-19 에 반대로 적었던 기대값을 고쳤다.
