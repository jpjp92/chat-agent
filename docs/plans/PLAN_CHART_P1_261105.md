## 1. 문제

- y축이 `200.0k`·`1000.0k` — 1000 이상이면 소수 한 자리 `k` 고정(한국어 화면에서 낯설고 `.0` 이 잡음).
- 단위가 어디에도 없다(명·원·%·N) — 스키마에 단위 필드가 없다.
- numeric 축 선은 마커가 없어 관측점(1970·1980·2000)과 그 사이 직선(보간)이 구분되지 않는다.
- 프롬프트 "1-2 data points 면 차트 금지" 가 "2024·2025 매출을 막대로 비교해줘" 같은 명시 요청까지 막는다.

## 2. 결정

**숫자 축약과 단위를 분리한다.** `yAxis.unit` 은 원자료 단위(`명`·`원`·`%`·`N`·`m/s²`), `만`·`억`(영어 `k`·`M`·`B`) 축약은 표시 포맷터가 맡는다.

| 위치 | 표시(unit = 명) | 단위 없음 |
|---|---|---|
| 헤더 | 제목 · `단위: 명` | 제목만(기존) |
| y축 눈금 | `20만`·`40만`·`100만` | 같음 |
| 툴팁 | `1,006,645명` | `1,006,645` |

- 축약: 한국어는 1만 이상 `만`, 1억 이상 `억`(소수 최대 1자리, `.0` 제거). 그 밖의 언어는 `k`·`M`·`B`. 1만 미만(ko)·1000 미만(그 밖)은 천 단위 구분만.
- **이중 축약 방지:** 모델이 이미 `만 명`·`억 원`·`천 톤` 처럼 축약 단위로 준 값은 다시 축약하지 않는다(천 단위 구분만) — `unit` 이 `만`·`억`·`천`·`조`·`k`·`M`·`B` 로 시작하면 축약 끔.
- 단위 붙이기: 한글 단위·`%`·`℃` 는 붙여 쓰고(`1,006,645명`·`3.5%`), 그 밖(`N`·`m/s²`·`USD`)은 한 칸 띄운다.
- `unit` 은 모델 출력 — 문자열·12자 이하·제어문자 없음만 받고 아니면 없는 것으로(React 가 이스케이프하므로 표시 위험은 없다).
- 히트맵 y 라벨(행 이름)·트리맵·히트맵 데이터 라벨은 손대지 않는다.

**관측점 마커는 데이터가 적을 때만.** numeric 축 선·영역에서 시리즈 점이 **10 개 이하**면 마커 4(관측점), 그보다 촘촘한 함수 샘플은 0. 산점도 6·결측 있는 선 4 는 기존 그대로. 마커는 시각 구분까지만 — 보간 구간 표기는 범위 밖.

**값 2개 막대는 프롬프트만 바꾼다.** "1-2개면 차트 금지" → 값 1개는 문장으로, **사용자가 비교 차트를 명시적으로 요청하고 비교 가능한 값이 2개 이상**이면 막대 허용. 없는 점을 지어내거나 기준이 다른 수치를 섞지 않는다(기존 규칙 유지).

**결측:** 선·막대 경로는 이미 `null` 을 유지한다(`chart-axis` 변환, 프롬프트 "0 으로 채우지 말 것"). 하니스로 회귀만 고정.
