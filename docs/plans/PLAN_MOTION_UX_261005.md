## 3. 계획

### 3-0. 0단계 — 죽은 애니메이션 살리기 (우선)

1. `globals.css` 에 프로젝트가 실제로 쓰는 조합만 키프레임 정의: `animate-in` + `fade-in` / `slide-in-from-{bottom,top,left}-{2,3}` / `zoom-in-95`.
   - 플러그인 설치 대신 직접 정의 — 쓰는 클래스가 한정적이고, 의존성 1개 + 의도치 않은 클래스 활성화를 피한다. Dialog 때와 같은 방식
2. **duration 정리**: 현재 700ms 8곳 · 1000ms 1곳 — 카드 등장으로는 길다. 등장은 200~300ms 로 맞춘다(기존 클래스 수정).
3. **새 메시지만 등장**: 메시지 목록 로드(세션 전환·기록 복원) 시점 이후에 추가된 id 만 애니 클래스를 받는다. 스트리밍 중 리렌더에서 재실행되지 않는지 확인.
4. reduced-motion 일괄: `@media (prefers-reduced-motion: reduce)` 에서 이 키프레임 전부 `animation: none`.
5. **49곳 육안 확인 목록**을 만들어 하나씩 본다 — 한꺼번에 살아나므로 어색한 곳(겹침, 레이아웃 점프)이 생길 수 있다.

  - ✅ **10-09 구현 — Thinking Orb** ([지시서](../../reference/CHAT_AGENT_THINKING_ORBS_IMPLEMENTATION.md) 검토 후 LLM 대기만 채택). `thinking-orbs@0.3.2`(MIT, 0.x 라 정확 버전 고정) `state="working" size={20}`, 인디고 틴트. [ChatArea.tsx](../../components/ChatArea.tsx) 점 3개 자리만 교체(높이 40px 동일 → 레이아웃 이동 없음). reduced-motion·화면 밖·숨은 탭 정지는 라이브러리 내장.
  - 고정 문구 대신 **이미 계산되지만 렌더되지 않던 `loadingStatus`**("이미지 분석 중…" 등)를 Orb 옆에 표시 — 4개 언어 문구 신설 불필요. 상태 없으면 Orb 만.

## 4. 추천 문구 재구성

> ✅ **10-05 구현** — 확정: 오늘 날씨 · 오늘 볼 영화(상영시간) · 최신 뉴스 · 이미지 분석(칩이 파일 선택 창을 연다, `prefill.attach`). 영화는 평점 데이터가 없고(`rating`=관람등급) "추천·요즘"이 상영표 규칙에서 제외되므로 **상영시간 조회**로 바꿨다. 규칙 판정: 날씨→weather, 영화→movie_search(ko·en), 뉴스→general+검색 on. 아래 §4-3 표는 초안이다.

### 4-1. 기준

추천 칩은 **"이 앱에서 처음 해볼 만한 것"** 이다. 고르는 기준:

1. **매일 쓸 이유가 있다** — 한 번 보고 마는 데모가 아니라 내일도 물어볼 질문
2. **이 앱이 더 잘하는 것을 보여준다** — 다른 챗봇과 같은 텍스트 답이면 칩으로 쓸 가치가 낮다. 카드·차트·출처가 붙는 질문
3. **실패하지 않는다** — 위치 권한, 로그인, 파일 첨부가 필요하면 첫 경험이 막힌다
4. **책임 부담이 없다** — 의료·법률은 기능은 있되 첫 화면 추천으로는 부적절

### 4-2. 현재 칩 평가

| 칩 | 판정 | 이유 |
|---|---|---|
| 최신 AI 뉴스 | 🟡 교체 | 출처 칩은 보여주지만 관심층이 좁다. 뉴스는 "오늘 주요 뉴스"가 더 보편적 |
| 오늘 볼 영화 | ✅ 유지 | 영화 카드 + 실시간 상영 — 이 앱만의 것. 다만 "강남 CGV" 고정은 지역 편향 |
| 약 복용 확인 | ❌ 제외 | 첫 화면에서 의료 조언 유도. 약 기능은 묻는 사람이 알아서 쓴다 |
| Python 자동화 | ❌ 제외 | 어느 챗봇이나 하는 것. 이 앱의 강점(카드·검색·시각화)을 하나도 안 보여준다 |

### 4-3. 제안 (ko)

| 아이콘 | 라벨 | 샘플 | 보여주는 것 |
|---|---|---|---|
| `fa-cloud-sun` | 오늘 날씨 | 오늘 서울 날씨 어때? 우산 챙겨야 할까? | 날씨 카드 · 매일 쓸 이유 |
| `fa-film` | 오늘 볼 영화 | 요즘 상영 중인 영화 중에 평점 좋은 거 추천해줘 | 영화 카드 · 지역 고정 제거 |
| `fa-chart-line` | 차트로 보기 | 최근 10년 한국 출생아 수 변화를 차트로 보여줘 | 차트 렌더러 — 다른 챗봇과 가장 다른 지점 |
| `fa-newspaper` | 오늘의 뉴스 | 오늘 주요 뉴스 5개를 출처와 함께 요약해줘 | 검색 + 출처 칩 |

**대안 후보** (위 하나와 교체 가능):
- `fa-brands fa-youtube` **영상 요약** — "이 유튜브 영상 핵심만 요약해줘: " (칩은 입력창만 채우므로 사용자가 링크를 붙인다). 강점이 분명하지만 링크가 없으면 바로 못 보낸다(기준 3)
- `fa-diagram-project` **그림으로 설명** — "HTTPS 연결 과정을 다이어그램으로 그려줘" (다이어그램 렌더러)

> ⚠️ 샘플 문구는 확정 전에 **실제로 보내서** 카드/차트가 뜨는지 확인한다 — 의도 분류가 다른 쪽으로 가면 칩이 오히려 앱을 못나 보이게 한다. 차트 샘플은 데이터 출처가 검색되는지도 함께 본다.

### 4-4. 모바일

- 모바일 숨김은 **의도된 설계**라 유지한다. 칩 문구·모션은 데스크톱 기준
- [SuggestChips.tsx](../../components/SuggestChips.tsx) 의 "모바일: 가로 스크롤 1줄" 주석만 실제 동작("모바일 숨김")으로 고친다

### 4-5. 다국어

라벨·샘플은 en/es/fr 도 같은 구성으로 번역한다. 날씨 샘플의 도시는 언어별로 바꾸지 않는다(서울 고정이 오히려 앱 정체성과 맞음 — 확인 필요).

## 5. 검증
