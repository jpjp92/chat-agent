## A. 사용자에게 깨져 보이는 것

### A1. LangChain 폴백 크래시 — `Cannot read properties of undefined (reading 'parts')`

SDK 경로가 빈 응답을 내면 LangChain 폴백으로 넘어가는데, **그 폴백이 죽는다.** 결과는 빈 화면이다.

```
Empty response - finishReason: UNEXPECTED_TOOL_CALL
SDK path failed for intent: data_viz — falling back to LangChain
LangChain path fatal error: Cannot read properties of undefined (reading 'parts')
```

- 오늘 `[TOOL AVAILABILITY]` 프롬프트로 **트리거 하나**를 줄였지만(§8-3), 폴백 경로 자체는 그대로 깨져 있다. 안전필터·응답 절단 등 다른 트리거로 언제든 재발한다.
- **해야 할 일**: 폴백 진입 시 응답 구조를 방어적으로 읽고, 실패하면 사용자에게 재시도 안내 문구라도 반환. 지금은 예외가 위로 전파돼 아무것도 안 보인다.
- 작업량 작고 체감 큼 — **A티어 1순위**.

### A2. 날씨 예보 아이콘이 전부 ☀️

현재 날씨가 `Cloudy`(구름 70%)이고 강수확률 20%인데 **5일 예보가 전부 맑음 아이콘**이다(한국어·영어 스크린샷 모두 동일). 하늘상태 코드 매핑이 의심된다.

- 카드는 우리 서비스의 대표 UI이고, **정보가 틀려 보인다**. 값(기온·강수확률)은 맞는데 아이콘만 어긋나면 오히려 신뢰를 깎는다.
- 확인 지점: `weatherTool`이 KMA 단기예보의 `SKY`/`PTY` 코드를 예보 항목에 넣는지, 넣는다면 렌더러 매핑이 맞는지. 현재 카드는 예보 아이콘을 어디서 얻는지부터 봐야 한다.
- 오늘 작업과 무관한 기존 동작이라 **별건**으로 잡되, A2로 둔다.

### A3. CGV 스크래핑 실패가 "상영 없음"으로 보인다 (2026-08-05 추가)

**증상**: 강남 영화 상영시간표에서 CGV 섹션만 `0편 · 회차 0 · 상영 회차 없음`. 같은 시각 메가박스는 정상(4편/20회차). 6분 뒤 재조회하니 **3편/22회차로 복구**됐다.

실측([DEV_260805 §8-6](../logs/2026/08/DEV_260805.md)):

```
1차   movies=0  cached=stale  age=373초   ← 화면이 본 값
2차   movies=3  total=22  ms=25361  cached=fresh
3차   movies=3  total=22  cached=fresh
```

**원인**: CGV 만 browserless 로 스크래핑한다(롯데·메가박스는 JSON API 직접 호출). 실패 경로가 **전부 빈 배열로 수렴**한다:

```ts
// app/api/showtimes/route.ts
const d = (JSON.parse(await res.text())).data || {};
if (!d.rows) return [];                     // browserless 실패 → []

// 브라우저 안
const mov = await get('/cnm/atkt/searchMovScnInfo', params);
if ((mov.data||[]).length) return { date: ymd, rows: mov.data };
return { date: dates[0], rows: [] };        // HMAC 서명 실패·응답 지연 → []
```

CGV API 는 HMAC 서명을 요구한다. 서명이 틀리거나 응답이 늦으면 `mov.data` 가 없고 → 빈 배열 → **진짜로 상영이 없는 것과 화면상 구분 불가.**

**두 가지가 겹쳐 나쁘다**:
1. 사용자는 "이 극장은 오늘 상영이 없구나"로 읽고 다른 관을 찾아 나간다 — 틀린 정보다.
2. 그 빈 결과가 **캐시에 저장돼** 6분 이상 지속된다. 새로고침해도 안 고쳐진다.

정상 소요가 `ms=25361`(25초)로 [Vercel 60s 천장](PLAN_BACKLOG_260801.md)에 가깝다는 것도 위험 요인이다 — 부하가 걸리면 조용히 0건이 된다.

**처방**: 실패와 빈 결과를 **구분**한다.
- `d.rows` 가 없으면 `throw` → `payload.error` 로 흘려 카드가 "조회 실패"를 표시(이미 그 UI 는 있다)
- 🔴 **실패는 캐시에 넣지 않는다** — 지금은 실패값이 stale 로 재사용돼 증상이 길어진다
- 브라우저 안의 `rows: []` 도 "빈 스케줄"과 "API 실패"를 구분해서 돌려줘야 한다(예: `{ ok: false }`)

**언어·i18n 과 무관하다.** 스페인어 테스트 중에 눈에 띄었을 뿐, 한국어에서도 같다.

## E. 하지 않기로 한 것

### E1. 날씨 카드 지명 i18n

영어 UI에서도 `서울`·`부산광역시`로 표시된다. KMA가 주는 지명이라 **틀린 정보는 아니고**, 고치려면 지명 매핑 테이블(한→영/스/프)이 필요하다. 해외 도시는 OpenWeather라 이미 영문이다. 비용 대비 값어치가 낮다.

### E2. 극장 인접 지점 대체

`노원 → 중계(CGV)`처럼 가까운 다른 동네를 대신 보여주는 것. **오늘 고친 가산디지털 문제와 같은 성격**이라 의도적으로 넣지 않았다. 지역 인접성 데이터가 필요하고, "어디까지가 근처인가"라는 기준이 생긴다. 지금은 "지점이 없습니다 + 드롭다운으로 직접 선택"이 정직하다.

### E3. 검색 on/off에 따른 수치 편차

2021년 실질 GDP 성장률이 검색 턴에서 4.3%(확정치), 비검색 턴에서 4.1%(속보치)로 나왔다. **둘 다 출처가 있는 값**이라 오류가 아니다. 통일하려면 "항상 검색"이 필요한데 지연·쿼터 비용이 크다.
