## 1. 결정 원칙 (사용자 지시, 10-10)

1. **게스트는 2.5 + 무료 키 로테이션.**
2. **유료 키 호출이 실패하면 2.5 로 폴백.** 게스트(무료 키)가 실패하면 "로그인 후 사용해주세요" 안내 — ✅ 10-10 구현(`forGuest`).
3. 업로드 영상·PDF 의 3.x 429 는 **재측정해서** 판단 → 10-10 2라운드 429 0건(§3-1).
4. **GPT 선택 + 영상·오디오** → Gemini 3.6 이 미디어를 분석(실패 시 2.5), **최종 응답은 GPT 가 정제**.
5. **GPT 선택 + PDF** → GPT 직접 처리 가능 여부를 개별 측정 → 가능(§3-2).

## 4. 설계

### 4-1. Gemini 경로 — `urlFileData` 를 키에 연결

- [models.ts](../../server/models.ts) `urlFileData` 를 3.6·3.7 `true` 로 — 단 **게스트(무료 키)는 원칙 1 로 어차피 2.5**. 즉 실제 변화는 "회원 + 유료 키면 3.x 직접".
- 유료 키 실패 → 무료 키 폴백 시 **모델도 2.5** — 기존 `searchFallbackFor` 와 같은 "시도마다 키로 재판정" 패턴을 미디어 핀에도 적용.

### 4-2. GPT + PDF — OpenAI 어댑터에 `input_file`

- [openai/chat.ts](../../server/openai/chat.ts) `toInputContent`: `fileData{mimeType:'application/pdf'}` → `{type:'input_file', file_url}`, `data:application/pdf;base64` → `{type:'input_file', filename, file_data}`.
- `pinOpenAIUnsupportedMedia` 에서 PDF 제외.

### 4-3. GPT + 영상·오디오 — 2단계

```
[1단계] Gemini (회원: 3.6·유료 / 게스트·실패: 2.5·무료)
        입력: 영상·오디오 + 사용자 질문
        출력: 상세 분석 텍스트(장면·발화·타임스탬프) — 사용자에게 스트리밍하지 않음
[2단계] GPT(사용자 선택 모델)
        입력: 사용자 질문 + [MEDIA_ANALYSIS] 1단계 결과 + 히스토리
        출력: 최종 응답(스트리밍) — 템플릿·언어·톤은 GPT 프롬프트 그대로
```

- 1단계 결과는 다음 턴용 컨텍스트로도 보존 — 현행 `[VIDEO_ANALYSIS_SUMMARY]` 왕복(lastActiveDoc)을 재사용.
- 지연: 1단계 10~14s + GPT 첫 토큰 → 대기 표시(Orb + `loadingStatus` "영상 분석 중")가 필요한 구간. 영상은 이미 heavy 턴 데드라인(48s)을 쓰므로 1단계에 같은 예산.
- 실패: 1단계 3.6 실패 → 2.5 재시도 → 그래도 실패면 현행 에러 문구. 2단계 GPT 실패 → **1단계 분석 원문을 그대로 출력**(가용성 우선)할지 §5.

## 5. 열린 질문

1. ~~GPT + YouTube~~ → 2단계에 포함(10-10). **현재 동작(코드 확인)**: YouTube URL 턴은 route 가 `fileData`(video/mp4) 를 붙이고 → `pinOpenAIUnsupportedMedia` → **Gemini 2.5 가 답 전체를 생성**한다. OpenAI 는 영상 입력이 없어 GPT 가 직접 볼 방법이 없다. 후속 턴은 영상 재전송 없이 `[VIDEO_ANALYSIS_SUMMARY]` 텍스트라 **GPT 가 답한다** — 첫 턴만 모델이 바뀌는 비대칭. 참고: `[TRANSCRIPT]` 를 만드는 코드가 현재 없다(route·search-gate 가 검사만 함) — 자막 경로는 사실상 죽은 분기.
2. 2단계 GPT 실패 시 1단계 원문 출력 vs 에러.
3. 게스트 + GPT + 영상의 비용 — 1단계 무료, 2단계 OpenAI 과금. 현행 게스트 GPT 정책과 동일하게 둘지.
4. GPT + 이미지가 히스토리에 남은 후속 턴 — 지금도 GPT 가 이미지를 다시 받는다(문제 없음, 확인만).
