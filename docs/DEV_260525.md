## 1. Supabase 신규 프로젝트 이전

### 배경

기존 Supabase 프로젝트(구 계정)를 신규 계정의 프로젝트로 전면 이전. DB 테이블 3개 + Storage 버킷 3개 마이그레이션.

### DB 마이그레이션

**신규 프로젝트 테이블 DDL 생성 순서** (FK 의존 순서 준수):
1. `users` — `GENERATED BY DEFAULT AS IDENTITY` (원본 id 유지 목적으로 최종 변경)
2. `chat_sessions` — uuid PK, `user_id` FK
3. `chat_messages` — bigint PK, `session_id` FK

**초기 이전 시 발견된 문제**:
- `GENERATED ALWAYS AS IDENTITY` 컬럼에 명시적 id 삽입 불가
- users 재삽입 시 새 id가 부여되어 기존 로그인 기기의 localStorage `chat_user` 캐시와 불일치 → FK 오류
- 해결: `ALTER TABLE public.users ALTER COLUMN id SET GENERATED BY DEFAULT;` → `TRUNCATE public.users CASCADE;` → id 포함 재마이그레이션
- 마이그레이션 완료 후 시퀀스 리셋: `SELECT setval(pg_get_serial_sequence('public.users', 'id'), 1054);`

**최종 이전 건수**:

| 테이블 | 건수 |
|---|---|
| `users` | 681건 |
| `chat_sessions` | 1,267건 |
| `chat_messages` | 4,223건 |

> Supabase JS 클라이언트 기본 limit 1000으로 인해 `count: 'exact'` 쿼리로 전체 건수 선확인 후 페이지네이션 적용.

**이전 대상**:

| `chat-videos` | 1개 | — |
| `chat-docs` | 59개 | — |
| **합계** | **172개** | |

- `srcDB.storage.from(bucket).download(path)` → `dstDB.storage.from(bucket).upload(path, blob, { upsert: true })` 방식
- DB URL 일괄 업데이트: `attachment_url` 117건, `avatar_url` 0건 (구 URL 미참조)
- URL prefix: `axpvmgndefueicehdetu.supabase.co` → `gaomgqnpsjtabrvwnpad.supabase.co`

### 환경변수 교체

`.env`, `.env.local` 모두 신규 프로젝트 값으로 교체. `npx vercel dev` 로컬 테스트 시 `.env`가 API 라우트에 우선 적용됨을 확인 (`.env.local`이 Vite 프론트에는 적용되나 Vercel CLI API 라우트는 `.env` 우선).

## 2. 3.5 Flash Stage2 날씨 표 형식 수정

### 문제

3.5 Flash Two-track Stage2 합성 결과에서 날씨 주간 예보가 불릿 포인트로 출력. 2.5 Flash는 표 형식으로 출력하는데 비해 일관성 없음.

### 원인

`synthesisInstruction` 규칙에 표 형식 강제 지침 없음 → Stage2가 Stage1 그라운딩 결과의 불릿 구조를 그대로 답습.

### 수정 (`api/_lib/agent/nodes/generator.ts`)

```ts
// 변경 전
'- Preserve useful structure, clarity, and brevity.',

// 변경 후
'- IMPORTANT: For weather forecasts, daily/weekly schedules, comparisons, or any multi-row structured data, you MUST use a markdown table. Never use bullet points for data that has consistent columns across multiple rows.',
'- Preserve useful structure, clarity, and brevity.',
```

### 결과

날씨 질의 시 3.5 Flash도 2.5 Flash와 동일한 표 형식으로 출력 확인.
